## Summary

TokenCount proposes a training-free object counting framework built on SAM. The core ideas are: (1) probabilistic prompt generation that iteratively samples prompt locations from a softmaxed similarity map, and (2) output token-based verification that uses SAM's decoder output tokens (instead of image embeddings) as discriminative features, with the TS-SS similarity metric. The method is evaluated on FSC-147 and CARPK.

## Strengths

1. **Novel use of SAM's output tokens for counting.** The idea of bypassing image-embedding similarity (which prior work like TFOC showed is ambiguous) and instead using SAM's decoder output tokens as discriminative features is creative and well-motivated. Section 3.2 explains how output tokens encode both semantic and positional information through bidirectional attention, and Figure 5 provides PCA-based evidence that output tokens separate positive/negative instances more cleanly than image embeddings do.

2. **Principled metric choice.** The argument (Section 3.2) that standard metrics (cosine similarity, L2 distance, dot product) each fail individually because output tokens jointly encode angular/semantic and magnitude/positional information is sound. The TS-SS metric (Eq. 2–3) is a reasoned hybrid, and Table 3 shows it outperforms alternatives (MAE 16.25 vs. 16.48 for cosine, 16.53 for L2, 19.58 for dot product).

3. **Well-structured ablation study.** The ablation on iteration count × prompts per iteration (Table 4), verification metric (Table 3), and verification criteria — output token vs. image embedding space (Table 5) — directly supports the paper's central claims about each component's contribution.

## Weaknesses

### Fatal
None.

### Major

1. **Abstract overclaims on the paper's own data.** The abstract states: *"Experimental results show our method achieves superior accuracy with an MAE of 16.25, outperforming existing training-based and training-free counting methods."* This is contradicted by Table 1. On FSC-147, four training-based methods achieve better MAE (BMNet+ 14.62, SAFECOUNT 14.32, PseCo 13.05, LOCA 10.79) and one training-free method (TFCAC 12.26) also beats it. The only domain where the method leads all training-based methods is CARPK, a single aerial parking lot dataset. The paper's own text in Section 4.2 correctly clarifies ("best performance among training-free SAM only methods"), but the abstract misrepresents the results. This is a factual inaccuracy that must be corrected.

2. **Extreme RMSE/MAE ratio is unanalyzed.** Across all experiments the RMSE is dramatically higher than the MAE: 8.2× on FSC-147 few-shot (RMSE=133.11, MAE=16.25) and 7.3× on one-shot. For comparison, LOCA's ratio is 5.3× and BMNet+'s is 6.3×. An 8.2× ratio means the method occasionally produces catastrophically wrong counts that dominate the squared error. Section 5 mentions "performance degradation in scenarios with dense distributions of very small instances" but provides no analysis — no per-category breakdown, no error distribution histogram, no identification of outliers. Without this, the reader cannot assess the method's reliability.

3. **Runtime advantage over TFCAC is unsubstantiated.** Section 4.2 states the method is "more than twice as fast" as TFCAC, but reports no runtime for TFCAC — only its own 1.69 seconds per image on FSC-147. This claim is not verifiable.

### Minor

4. **No variance or confidence intervals reported.** No table reports standard deviations or error bars. Since the probabilistic prompt generation involves stochastic multinomial sampling, results must have non-trivial variance across runs. Differences as small as 16.25 vs. 16.48 (TS-SS vs. cosine, Table 3) or 16.25 vs. 16.94 (output token vs. image embedding, Table 5) may not be meaningful without variance estimates.

5. **SAM variant not specified.** The paper does not state which SAM variant is used (ViT-B, ViT-L, or ViT-H). The image embedding dimensions (64×64×256) suggest ViT-H, but this should be explicit for reproducibility.

6. **No hyperparameter sensitivity analysis.** The temperature τ (0.066) and verification threshold (300) are critical hyperparameters with no sensitivity study. The early stopping mechanism (IoU=0.95, patience=5) is described only in the ablation section (4.4), not in the method section (3), so a reader of Section 3 alone cannot reconstruct the full algorithm.

7. **Anomalous result in ablation table unexplained.** In Table 4, with 128 prompts per iteration, performance degrades from 16 iterations (MAE 16.25) to 32 iterations (MAE 16.65), even though early stopping is applied. The paper does not comment on this.

### Trivial
None.

- Showing failure case visualizations alongside successful ones would strengthen credibility.
