# Final Review Report

## Summary

This paper presents PELICAN, a two-stage adaptive tutoring framework that combines collaborative cognitive diagnosis with dynamic instructional adaptation for personalized education. In Stage 1, the teacher (LLM) diagnoses a student's cognitive state through a successor-first questioning strategy with an expert-assistant-verifier pipeline for question correctness. In Stage 2, based on the diagnosed cognitive state, the framework uses a fast-slow thinking mechanism (dual-system theory) to select teaching strategies from a predefined pool, with slow-thinking constructing a Simulated Teaching Tree to simulate dialogue paths before selecting the optimal strategy.

The paper addresses a genuine and important problem: current LLM-based tutoring produces correct but cognitively undifferentiated responses that fail to adapt to individual student needs. The framework is well-structured, combining ideas from cognitive diagnosis, hierarchical knowledge modeling, and dialogue planning. Evaluation on the Gaokao dataset with simulated students shows improvements in diagnostic accuracy and tutoring coverage over baselines, and a human pilot with 169 high school students provides preliminary real-world validation.

**Core weaknesses**: The main experiments rely on LLM-simulated students rather than real learners, which limits external validity. The GPT-based evaluation uses the same model family (GPT-4o) for both generation and assessment, introducing circularity risk. The contribution framing overlaps with method description rather than establishing independent scientific novelty. The slow-thinking scoring function (Eq. 5) lacks a principled reward signal incorporating learning outcomes. Additionally, the knowledge propagation logic in hierarchical diagnosis has a logical tension between strict prerequisites and diagnostic value. These issues collectively reduce confidence in the claimed improvements (+18.7% critical thinking, +22.4% task completion) and the overall novelty positioning. External literature verification was unavailable in this run (Retrieval-Disabled Mode); novelty conclusions require manual verification.

## Strengths
1. **Addresses a well-motivated problem**: The paper identifies a genuine limitation of current LLM-based tutoring — producing correct but cognitively undifferentiated responses — and proposes a structured approach to address it. The problem framing is clear and practically relevant.

2. **Two-stage framework with principled design**: The separation into collaborative cognitive diagnosis followed by adaptive tutoring is a sensible architectural choice. The successor-first diagnostic strategy and the hierarchical knowledge representation are well-motivated by pedagogical principles.

3. **Dual-system theory for strategy selection**: Applying dual-system theory (fast thinking for routine responses, slow thinking for persistent challenges) to tutoring strategy selection is a creative and potentially impactful idea. The Simulated Teaching Tree, while related to MCTS, is a novel application to educational dialogue planning.

4. **Real-world human evaluation**: The pilot study with 169 high school students (1,335 tutoring reports) is a significant effort that strengthens the paper beyond pure simulation. Ethical considerations (parental consent, anonymization) are properly documented.

5. **Reproducibility considerations**: The paper provides code access, uses a public dataset (Gaokao), and includes implementation details (model versions, hyperparameters, token consumption). This supports reproducibility despite the complexity of the pipeline.

6. **Rich qualitative analysis**: The case study (Figure 5) and strategy distribution analysis (Figure 4) provide concrete insights into how the framework adapts to different cognitive levels, helping readers understand the practical behavior of the system.

## Weaknesses
### W1. Main experiments use simulated rather than real students (Critical)

The core experimental results (Tables 1-4) are conducted using LLM-simulated students whose cognitive states and responses are generated by GPT-4o. While simulation enables controlled evaluation, it fundamentally limits external validity. The "critical thinking stimulation (+18.7%)" and "task completion rates (+22.4%)" cited in the abstract derive from these simulated evaluations, not from real educational outcomes. The human study (Section 4.6, N=169) is presented separately with different metrics, and its success rate advantage over baselines is modest (0.3pp over Sepwise). **Recommendation**: The abstract and conclusion must explicitly state that main results are simulation-based. Add a "Limitations" subsection discussing threats to external validity from LLM-based student simulation. Include correlation analysis between simulated and real-student outcomes.

### W2. GPT-based evaluation circularity (Major)

The framework uses GPT-4o for both generation and evaluation across subjective dimensions (Suitability, Inspiration, Reliability). This creates a risk that the evaluator systematically favors responses matching its own stylistic patterns rather than measuring true tutoring quality. The near-ceiling Reliability score of 4.51/5 for PELICAN (vs 3.67 for the next best) is especially concerning. **Recommendation**: Use a different model for evaluation, report human-GPT correlation, and include bias discussion in limitations.

### W3. Contribution framing overlaps with method description (Major)

The three contribution bullets describe what the system does rather than what scientific question it answers or what new insight it provides. Contribution 1 is a restatement of the title+method. Contribution 2 ("slow-thinking algorithm") does not differentiate from MCTS-based dialogue planning. Contribution 3 is evaluation, not a contribution. The paper would benefit from framing contributions around the novel *mechanism* (e.g., hierarchical cognitive state estimation with successor-first diagnosis) rather than the system-level pipeline. **Recommendation**: Rewrite contributions to state the specific problem, the novel mechanism, and the evidence establishing the mechanism's effectiveness (see annotation on Page 1 - Introduction).

### W4. Logical issue in knowledge propagation during diagnosis (Major)

The diagnostic rule "if v is mastered, all its prerequisite nodes are also updated to 1" creates a logical tension. If the prerequisite hierarchy is strict (child requires parent mastery), then mastering a child already implies parent mastery, making propagation trivial. If the hierarchy is not strict, propagation may be unsound. This affects confidence in the diagnostic accuracy reported in Table 1. **Recommendation**: Clarify whether the hierarchy is strict or probabilistic and explain what diagnostic value the propagation adds. Include verification steps for false-positive propagation.

### W5. Simulated Teaching Tree scoring lacks principled reward signal (Major)

The slow-thinking scoring function (Eq. 5: score = 1 - λ×(d-1)) penalizes depth but does not directly incorporate whether the simulated student actually learned. The binary mastery check only excludes nodes from further expansion but is not integrated into the score. The 230K token cost (~40% of total) for this mechanism yields a modest 5.4-point improvement in ablation (Table 3). **Recommendation**: Incorporate mastery outcome directly into the score. Add ablation comparing full slow-thinking vs. a simpler heuristic variant to isolate tree-search value.

### W6. Unsupported generalization claims in conclusion (Major)

The conclusion states effectiveness "across various subjects and cognitive states," but experiments only use mathematics questions from the Gaokao dataset (184 questions). Cognitive states are simulated, not measured from real students. **Recommendation**: Replace "various subjects" with "mathematics questions" and add explicit limitations about generalization to other subjects and real-world settings.

### W7. Weak correctness guarantee from expert-assistant-verifier pipeline (Major)

The pipeline assumes LLM-LLM agreement implies correctness, but both models may share systematic biases (e.g., arithmetic errors, reasoning fallacies). No analysis is provided on how often the pipeline detects inconsistencies or how often both models agree on an incorrect answer. The 1.01-point F1 improvement over No-Pipeline (Table 1) suggests the pipeline's actual contribution to accuracy is modest. **Recommendation**: Provide human-validated error analysis of pipeline outputs and acknowledge the limitation.

### W8. Missing statistical rigor in human evaluation (Major)

The human study reports success rates (PELICAN 86.8% vs Sepwise 86.5%) without confidence intervals or significance tests. The small absolute differences on key metrics prevent readers from assessing whether improvements are statistically reliable. **Recommendation**: Add pairwise significance tests, confidence intervals, and effect sizes for all human-study metrics.

### W9. Limited novelty positioning relative to existing methods (Verification needed)

The paper does not clearly distinguish its contributions from prior work in several dimensions: (a) Simulated Teaching Tree resembles MCTS for dialogue planning, (b) successor-first diagnosis is related to adaptive testing algorithms, (c) expert-assistant-verifier is similar to LLM self-consistency verification. Without explicit comparison in the paper, the novelty boundaries are unclear. **Note**: External literature verification was unavailable in this run. Manual verification is required to assess novelty against the strongest relevant baselines.

### W10. Missing discussion of limitations (Minor)

The paper has no dedicated Limitations section. Critical limitations — simulated students, GPT evaluation circularity, single-subject evaluation (math only), lack of long-term learning outcome measurement — are either absent or dispersed. **Recommendation**: Add a "Limitations and Future Work" section consolidating these issues.

### W11. Introduction narrative could be sharper (Minor)

The first two paragraphs define personalized learning broadly and critique LLMs, but the transition from problem to the paper's specific solution is insufficiently motivated. The "Figure 1" paragraph does not preview the paper's methodological insight. **Recommendation**: Restructure introduction to follow: specific gap in prior work → key insight (cognitive state modeling) → method preview → contribution statements (see annotation on Page 1 - Introduction).

### W12. Related work reads as list rather than comparative analysis (Minor)

The related work sections summarize papers but do not organize them along decision-relevant axes (e.g., how student state is represented, how strategies are selected). **Recommendation**: Reorganize by comparison dimensions (state representation, strategy selection mechanism, evaluation method) and explicitly state PELICAN's position on each axis.

### W13. Inconsistent notation and missing symbol definitions (Minor)

The method uses Φ_Gen_c, Φ_Gen_top, Φ_Sim_T, Φ_Sim_S, Φ_Gen_res without defining what these functions are (neural network, prompted LLM, rule?). The penalty parameter is called λ in Eq. (5) but φ in implementation details. **Recommendation**: Define all Φ functions explicitly and ensure symbol consistency between equations and implementation descriptions.

## Score
**Final Score: 5.5/10**

**Rationale**: The paper addresses a worthwhile problem and presents a technically coherent framework. The two-stage architecture, successor-first diagnosis, and dual-system-inspired strategy selection are sensible design choices. The real-world pilot with 169 students is a strength that distinguishes this work from purely simulation-based tutoring papers.

However, the score is constrained by several significant concerns:
- **Research value uncertainty**: The main experimental results are from simulated students, not real learners. The claimed improvements (+18.7%, +22.4%) derive from GPT-based evaluation of simulated tutoring, which creates circularity risk and limits external validity.
- **Novelty positioning is unclear**: External literature verification was unavailable in this run, but the paper's own description suggests that key components (successor-first diagnosis, simulated teaching tree) may overlap significantly with existing adaptive testing and MCTS-based dialogue planning methods. Contribution claims need tighter framing.
- **Methodological rigor gaps**: The knowledge propagation logic has a logical tension, the slow-thinking scoring function lacks a principled reward signal, and the expert-assistant-verifier pipeline provides a weak correctness guarantee.
- **Statistical reporting is incomplete**: The human evaluation lacks significance tests, confidence intervals, and effect sizes.

The paper has a solid foundation but requires substantial revision in experimental framing, statistical rigor, and contribution positioning before it can be considered for acceptance. The most critical revision item is transparent reporting of the simulation-based evaluation and addition of a dedicated limitations section.
