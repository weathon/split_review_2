## Summary
This paper proposes Forest-based Graph Learning (FGL), a new paradigm for semi-supervised node classification that uses spanning trees as the propagation substrate to achieve efficient long-range information aggregation. The key insight is that a spanning tree is the minimal subgraph connecting all nodes, offering global coverage at low complexity. FGL consists of four components: (1) pre-processing that adds edges via pseudo-label k-NN to ensure connectivity and improve homophily; (2) a homophily-estimator-based tree sampler (using local attention) that biases tree sampling toward higher-homophily spanning trees via the weighted Wilson algorithm; (3) a general tree aggregator that propagates messages along each tree in linear time via two recursions (Combine/Disentangle), enabling quadratic node-pair interactions; and (4) a tree fuser that averages outputs from multiple trees with a local residual connection. The paper provides a theoretical analysis (Theorem 2) showing that the expected edge homophily ratio of sampled trees increases monotonically with the ratio of homophilous-to-heterophilous edge scores, approaching a structural upper bound. Experiments on nine benchmarks with 26 baselines show that FGL achieves competitive or superior accuracy while maintaining higher efficiency (2-5× speedups over efficient baselines on most datasets).

The core technical novelty—using spanning tree distributions for graph message passing—appears conceptually interesting, but its relation to existing tree-based and rewiring approaches (e.g., TreePiece, GraphGPT, EXACT, Tree-GNN, random rewiring methods) could not be verified against the literature.

## Strengths
1. **Conceptually clean and well-motivated framework.** The core insight—using spanning trees as the minimal global-coverage substructure for message passing—is intuitive and theoretically grounded. The cost decomposition (Eq. 1) provides a clear conceptual lens for understanding the efficiency-global coverage tradeoff, and the choice of spanning trees follows naturally from this analysis. The forest-based extension (multiple trees) addresses the limitation of a single tree missing complementary topological pathways.

2. **Theoretical analysis connecting homophily estimation to tree quality.** Theorem 2 provides a formal link between edge-score ratios and the expected homophily of sampled trees, with monotonicity and asymptotic tightness guarantees. This is a non-trivial theoretical contribution that justifies the homophily-guided sampling strategy.

3. **Efficient and potentially general tree aggregator.** The two-recursion formulation (Combine/Disentangle properties) is an elegant insight that allows any aggregator satisfying the properties to be used on trees in linear time. The linear-time implementation (Eq. 7-8) with quadratic expressiveness is a meaningful algorithmic contribution. The parallelization discussion (centroid root, greedy priority) shows awareness of practical efficiency concerns.

4. **Strong empirical performance on heterophilous graphs.** FGL achieves particularly large gains on heterophilous datasets (Cornell, Texas, Wisconsin, Actor) where traditional GNNs struggle. For example, on Texas (91.89 vs 78.92 for SGFormer) and Cornell (83.24 vs 76.76 for Graphormer), the improvements are substantial and suggest genuine advantage in settings requiring long-range propagation.

5. **Comprehensive experimental design.** The paper compares against 26 baselines spanning multiple categories (classic GNNs, deep GNNs, Graph Transformers, Mamba) across 9 diverse benchmarks. The ablation studies (Table 3) and homophily estimator comparisons (Table 4) provide useful diagnostics for understanding the contribution of each component. The hyperparameter study on tree count (Fig. 4) demonstrates robustness to the main design choice.

## Weaknesses
### Major Weaknesses

**W1. Pre-processing pseudo-labels introduce risk of label leakage (Page 1 - Sec 4.1).** The pre-processing step computes pseudo-labels from labeled nodes and uses them to add k-NN edges to the augmented graph. The downstream pipeline (tree sampling, tree aggregation) then operates on this augmented graph. This creates a potential circular dependency: label information influences graph structure, which then influences node embeddings for classification. The paper does not discuss or control for this leakage risk. An ablation comparing FGL with and without pre-processing is missing from the main ablation table (Table 3), so the reader cannot separate the gain from tree-based propagation from the gain from simply adding homophilous edges. This confound weakens the core claim that the forest-based paradigm is responsible for performance improvements. *Fix: Add an ablation using the original graph without pre-processing, report deltas, and discuss leakage risks.*

**W2. Tree aggregator generality claim is unsubstantiated (Page 1 - Sec 4.3).** The paper claims that the tree aggregator framework accommodates "any general message aggregator" satisfying Properties (I) and (II), citing linear attention, linear RNNs, and SSMs as examples. However, it does not verify that these specific families satisfy the Combine/Disentangle properties, nor does it define what "deleting" ($\mathcal{M}^-$) means for non-invertible aggregators (e.g., SSMs with non-invertible state transitions). Without concrete examples or proof sketches, the generality claim remains a promissory note. The actual implementation uses only the linear weighted-sum variant (Eq. 7-8), which is a simple special case. *Fix: (a) Provide explicit Combine/Disentangle operators for at least one non-trivial aggregator (e.g., linear attention or LRU). (b) Acknowledge that non-invertible aggregators may only approximately satisfy Property (II).*

**W3. Missing standard deviations and significance testing in main results (Page 1 - Sec 5, Table 1).** Table 1 reports only mean accuracy without standard deviations. The paper directs readers to the appendix (Table 10) for variance, but the main table and narrative claims rely solely on means. For small-margin comparisons (e.g., Cora: 85.46 vs 85.35 TDGNN; Citeseer: 74.42 vs 74.46 DIFFormer), the ranking could reverse with variance. The paper reports "ten different initializations" but does not report confidence intervals or significance tests. *Fix: Report mean±std in Table 1 or a companion main-text table. Add paired significance tests against top-3 baselines.*

**W4. Theorem 2 assumes binary edge scores; bridge to continuous attention outputs missing (Page 1 - Sec 4.6).** Theorem 2 provides a clean theoretical result assuming edge scores take only two values ($p$ for homophilous, $q$ for heterophilous). However, the actual homophily estimator (Eq. 3) produces continuous attention scores in $[0,1]$. The paper asserts that "as edge-homophily estimates improve, the induced distribution biases towards higher-homophily trees," but the link between continuous attention scores and the binary $p/q$ model is not established. The concept of NHCC (Number of Homophilous Connected Components) is introduced but not formally defined. *Fix: Add a remark explaining the connection (e.g., thresholding interpretation or probabilistic mapping). Precisely define NHCC.*

**W5. Complexity analysis is underspecified (Page 1 - Sec 4.5).** The analysis states $\mathcal{O}((n+m)Kd)$ per epoch but omits several components: (a) Wilson's algorithm complexity (amortized $O(n)$ per tree, but worst-case can be higher); (b) topological sort cost for tree traversal; (c) the $O(d^2)$ matrix multiplication cost in Eq. 7-8 (the $W_A$ and $W_B$ matrices are $d \times d$, not $d$-dimensional). The term $(n+m)$ mixes original edges ($m$) with tree operations ($n$ nodes per tree), which is misleading since trees have exactly $n-1$ edges. *Fix: Decompose complexity by component. Clarify that per-tree aggregation is $O(n d^2)$ due to matrix-vector products, not $O((n+m)d)$.*

**W6. Ablation does not isolate pre-processing contribution (Page 1 - Sec 5, Table 3).** The ablation studies compare five variants but none removes the pre-processing step (k-NN edge addition). Without ablating the graph augmentation, the reader cannot determine whether FGL's gains come from the forest-based propagation or from the added homophilous edges alone. Given that pre-processing "increases the homophily ratio," which is known to improve GNN performance, this is a critical confound. *Fix: Add an ablation variant (Variant 6) applying FGL on the original graph $G$ without pre-processing.*

**W7. Conclusion lacks limitations and overstates scope (Page 1 - Sec 6).** The conclusion presents only strengths and positions FGL as "a significant step towards the future development of long-distance graph learning" without acknowledging any limitations. This is a missed opportunity for scientific credibility. Important limitations to discuss include: dependence on pseudo-label quality, sensitivity to the k-NN parameter, theoretical assumptions (binary scores, connected graph), and potential failure cases under extreme heterophily. *Fix: Add a limitations paragraph discussing these points. Replace promotional tone with balanced summary of validated findings and open challenges.*

### Minor Weaknesses

**W8. Abstract claim inconsistency (Page 1 - Abstract).** The abstract says "comparable results against state-of-the-art counterparts" while the contribution list claims "11.90% and 16.14% average relative gains." "Comparable" understates what the authors claim as significant gains, creating a trust gap. *Fix: Align abstract wording with contribution claims (e.g., "competitive or superior accuracy").*

**W9. Introduction P1 uses literature-listing opening (Page 1 - Introduction).** The first paragraph lists numerous GNN applications before reaching the limitation, delaying the core motivation. *Fix: Restructure to present the GNN receptive-field limitation in the first two sentences, then cite applications briefly.*

**W10. Introduction P2 overstates "inherent limitation" claim (Page 1 - Introduction).** The claim that the trade-off is "rooted in the inherent limitation of existing learning paradigms" is presented as fact but is an opinion (no formal impossibility proof is given). *Fix: Soften to "a fundamental challenge that existing designs struggle to resolve."*

**W11. Tree Fuser Eq. (9) has undefined $\alpha$ term (Page 1 - Sec 4.4).** The $\alpha$ in Eq. (9) is not explicitly defined—it is unclear whether it refers to the attention coefficients from Eq. (3) or another matrix. *Fix: State explicitly: $\alpha$ denotes the attention score matrix from Eq. (3).*

**W12. Method opening paragraph redundant (Page 1 - Sec 4 opening).** The first paragraph of the Method section largely repeats the cost trade-off already discussed in the Introduction. *Fix: Begin directly with the FGL framework overview.*

**W13. Efficiency comparison missing hardware configuration (Page 1 - Sec 5).** Running time comparisons (Table 2) do not specify GPU model, CPU, or software versions, making the comparisons non-reproducible. *Fix: Report hardware and software configuration in a footnote.*

**W14. Related Work positioning claim ambiguous (Page 1 - Sec 2).** The claim that FGL addresses the dilemma "from a more fundamental perspective" is not concretely differentiated from hybrid GNN-Transformer designs. *Fix: Replace with explicit comparison dimension (combinatorial minimality, structural guarantee).*

## Score
**Final Score: 6/10**

**Scoring rationale.** This score reflects the paper's genuine conceptual novelty (spanning-tree-based message passing is a fresh perspective), solid theoretical analysis (Theorem 2), and strong empirical results on heterophilous graphs. However, the score is constrained by several factors:

- **Validity risks (major):** The pre-processing step (k-NN edge addition from pseudo-labels) creates potential label leakage that is not controlled or ablated, weakening causal attribution of the performance gains to the forest-based paradigm. The generality claim of the tree aggregator is not substantiated beyond the linear weighted-sum case.

- **Evidence sufficiency (moderate):** Standard deviations and significance tests are relegated to the appendix; the main table reports only means. Some relative gain claims are calculated against weak baselines (e.g., vanilla GT) rather than strongest competitors.

- **Writing/presentation issues (minor):** Abstract-to-introduction inconsistency, redundant paragraphs, undefined notation in Eq. (9), and lack of limitations discussion reduce clarity and scientific completeness.

- **Novelty (deferred):** External literature comparison was not available in this run, so novelty verdicts are provisional. The core idea of using spanning trees for graph-level propagation appears novel within the reviewed manuscript, but its overlap with existing tree-based and rewiring approaches could not be independently verified.

The paper has strong conceptual foundations and promising empirical results, but several methodological gaps (especially the pre-processing confound and the unsubstantiated generality claim) need to be addressed before the claims can be fully trusted.
