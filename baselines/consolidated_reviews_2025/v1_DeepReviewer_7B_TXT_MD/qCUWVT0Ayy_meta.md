## Summary

This paper introduces LayoutNUWA, a novel approach to layout generation that reframes the problem as code generation. The core idea is to represent layouts as HTML code, which allows the leverages the semantic understanding and generative capabilities of large language models (LLMs). The proposed method, LayoutNUWA, employs a three-stage process: Code Initialization (CI), Code Completion (CC), and Code Rendering (CR). In the CI stage, the input data, such as category and size, is converted into HTML code with masked elements. The CC stage then uses an LLM to fill in these masked elements, generating a complete HTML structure. Finally, the CR stage renders the completed HTML code into the final layout. The authors evaluate LayoutNUWA on three datasets: RICO, PubLayNet, and Magazine, demonstrating state-of-the-art performance compared to existing methods. The key contribution of this work lies in its novel problem formulation and the integration of LLMs for layout generation, which the authors claim leads to more semantically rich and accurate layouts. The paper presents a well-structured methodology and provides empirical evidence of the effectiveness of the proposed approach. However, as I will detail in the following sections, there are several limitations that warrant further consideration.
