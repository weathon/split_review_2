## Summary

LUMA is a multimodal benchmark dataset (image, audio, text, 50 classes) designed for uncertainty quantification research. It extends CIFAR-10/100 images with audio from three speech corpora and text generated by Gemma-7B, and provides a Python toolkit for controlled injection of diverse uncertainty types (data diversity, sample noise, label noise, OOD samples). Baseline experiments with three UQ methods (MCD, DE, RCML) demonstrate that the dataset can differentiate between methods — notably, MCD/DE achieve ~0.5 OOD AUC while RCML achieves 0.91.

## Strengths

1. **Controlled injection of diverse, realistic uncertainty types per modality**: The Python toolkit independently controls data diversity (via deep-feature distance sampling, Eq. 1), sample noise (realistic perturbation types from nlpaug and Hendrycks et al.), label noise (nearest-class switching using deep features), and OOD injection (held-out classes from the same dataset). This goes beyond prior work that only adds Gaussian noise to features (Section 2).

2. **Dataset reveals meaningful differences between UQ methods**: Baseline experiments show MCD and Deep Ensemble achieve ~0.5 AUC for OOD detection on LUMA, while RCML achieves 0.91 (Table 2). Under increasing label noise, only RCML consistently raises both aleatoric and epistemic uncertainty (Figure 4). This demonstrates the dataset's ability to discriminate the quality of uncertainty estimates.

3. **Rigorous validation and bias mitigation across modalities**: Audio is validated via Whisper transcription plus manual annotation (17 annotators, 71.61% agreement, Section 3.2). Text is validated by masking labels and re-classifying (Section 3.3). Gender bias is explicitly detected and mitigated in four classes ("man", "woman", "boy", "girl") through prompt reconstruction (Section 3.3). This level of quality control is absent in prior multimodal uncertainty benchmarks (Section 2).

4. **Novel diversity control mechanism**: The parameterized sampling scheme (Eq. 1) adjusts data concentration in latent space using deep features (Wav2Vec, BERT, VGG-11), enabling fine-grained control over epistemic uncertainty by varying information density — a more principled approach than uniform or random subsampling.

5. **Open-source Python package**: The dataset generation and uncertainty injection functions are released as a Python package (footnote 1), enabling the community to generate custom dataset variants with different noise levels and types.

This creates circularity: Gemma-7B's own generation patterns are easier for itself to recognize, potentially inflating the validation pass rate. The paper acknowledges bias concerns in generation but does not address this validation concern. Cross-validation with a different classifier would strengthen this. This does not invalidate the dataset but weakens the claim that the text modality is independently validated.
