## Summary

The paper proposes RA-TTA, a test-time adaptation method for vision-language models (VLMs) that retrieves external images from a web-scale database (LAION-2B) using fine-grained text descriptions. The key innovation is a two-step description-based pipeline: (1) description-based retrieval selects text descriptions (generated by LLMs) that match a test image's pivotal features via image-to-text similarity, then retrieves external images via text-to-image similarity; (2) description-based adaptation refines predictions using a "semantic gap" measure computed between test and retrieved images via optimal transport. The paper evaluates on 17 datasets and reports improvements over prior methods (2.49–8.45% average gains), with particularly large gains on fine-grained and specialized-domain datasets.

## Strengths

- **Description-based retrieval is clearly shown to outperform naive image-to-image retrieval.** Table 3 (Var. 1 vs. Var. 2) cleanly isolates this: switching from image-to-image retrieval to description-based retrieval (with a simple cosine-similarity adaptation) improves accuracy on FGVC Aircraft. This directly supports the paper's core claim that text descriptions enable retrieval of images with the test image's pivotal features.

- **Additive contribution of each component is demonstrated via a properly structured ablation.** The ablation design (Var. 1 → Var. 2 isolates retrieval, Var. 2 → Var. 3 isolates adaptation, Var. 3 → RA-TTA isolates image weighting) is well-constructed and shows cumulative gains from each added component.

- **Consistent SOTA results across a large benchmark (17 datasets) with especially strong gains on data-scarce or specialized domains.** On fine-grained datasets (FGVC Aircraft, Flowers102, Stanford Cars) and specialized domains (RESISC45), RA-TTA shows large improvements over baselines, which aligns with the paper's motivating claim that external knowledge is most beneficial when pre-training data is insufficient.

- **Effective handling of natural distribution shifts that goes beyond text-description-only methods.** Table 2 shows RA-TTA improves ImageNet variant accuracy by 9.18% over ensemble prompting, while description-only methods (CuPL, WaffleCLIP) show minimal or negative gains. This isolates the contribution of external image retrieval beyond fine-grained text descriptions.

- **Training-free and adaptive retrieval.** RA-TTA retrieves images on-the-fly per test image, unlike static retrieval methods (SuS-X, Neural Priming), enabling adaptive handling of distribution shifts. The method also shows reasonable hyperparameter robustness (Figure 5).

## Weaknesses

### Fatal
None.

### Major

- **No deduplication or decontamination of the external database relative to evaluation test sets.** The paper constructs an external image database from LAION-2B using keyword matching on captions containing target class names, following prior work (Wallingford et al., 2023; Parashar et al., 2024). However, LAION-2B is known to contain images from standard benchmark datasets (including ImageNet and its variants), and the paper performs no analysis or verification that the retrieved images do not overlap with the test distributions of the 17 evaluated datasets. If test-set images or near-duplicates are in the database, the adaptation step could receive an unfair signal. While this concern is partially mitigated because (a) all retrieval-based baselines (SuS-X-LC, Neural Priming) use the same database and (b) the pseudo-labels are derived from captions, not ground-truth labels, the paper should address this directly — either by demonstrating decontamination or by showing results on a held-out subset that provably does not overlap. Without this, the empirical claims carry a meaningful confound that the community will rightly question.

### Minor

- **No variance or error bars reported.** The main results (Tables 1, 2) and ablations (Table 3, Figure 5) report single accuracy values without standard deviations, confidence intervals, or multiple runs. Given the stochastic components (augmentation, retrieval, OT aggregation), results may vary. While single-run evaluation is standard practice for many baselines in this field, reporting variance on at least a representative subset of datasets would strengthen the evidence.

- **Ablation conducted on only one dataset (FGVC Aircraft).** The paper is transparent that the ablation uses FGVC Aircraft "where the benefit of RA-TTA is significant." However, the relative importance of each component may differ across dataset types (e.g., general vs. fine-grained). Running the ablation on at least one additional dataset (e.g., ImageNet or DTD) would provide stronger evidence that all components are universally beneficial.

- **No justification for why optimal transport (OT) is needed over simpler aggregation.** The semantic gap scores are aggregated via OT (Eq. 8), but the paper does not ablate or motivate why OT is specifically required rather than, e.g., a weighted average or other simpler aggregation. Since OT adds complexity, a brief justification or ablation of the aggregation method would improve the paper.

- **No discussion of computational cost or latency.** For a test-time adaptation method, per-image latency matters. The pipeline involves generating M=100 augmentations, image-to-text similarity search over L descriptions per class, text-to-image search over a large database, and OT computation — but no runtime analysis is provided. This is relevant for practitioners assessing practical deployability.

### Trivial

- The paper refers to "20" descriptions per class in the introduction but does not explicitly restate the value of L in the experimental setup (Section 3 mentions "L text descriptions" without specifying L).

## Nice-to-Haves

- **Simple kNN baseline on retrieved images.** A useful additional baseline would be: retrieve K nearest images from the database via image-to-image similarity, then classify the test image by majority vote of the retrieved images' pseudo-labels. This would establish a lower bound for the benefit of retrieval alone and help calibrate the reader's expectations.

- **Variant using description-based retrieval with simple prototype averaging for adaptation** (and conversely, image-to-image retrieval with the full OT-based adaptation). While the existing ablation does isolate components step-by-step, these cross-variants could more directly demonstrate that the description-based approach adds value at both stages independently.

- **Ablating the OT aggregation vs. a simpler weighted average** to justify the additional complexity.

## Removed Points

- **"Ablation conflates multiple components"** — Removed. The paper's ablation (Var. 1 → Var. 2 isolates retrieval, Var. 2 → Var. 3 isolates adaptation, Var. 3 → RA-TTA isolates weighting) is a proper step-by-step design. The critic's claim that Var. 1 disables both retrieval and adaptation "simultaneously" misreads the design: Var. 2 has description-based retrieval enabled but description-based adaptation disabled, making the Var. 1→Var. 2 comparison a clean isolation of the retrieval component.

- **"Circular dependency between retrieval and adaptation descriptions"** — Removed. Using the same descriptions in both stages is by design, not a flaw: the descriptions identify the test image's pivotal features, which are then used consistently to retrieve relevant images and to assess relevance. There is no circularity — the descriptions are generated offline from LLMs and are independent of the test image.

- **"Number of descriptions per class not specified"** — Removed. The paper states "Multiple (e.g., 20) fine-grained visual features for each target class" in the introduction (Section 1) and defines "L text descriptions" per class in Section 2.4. The value L=20 is clear.

- **"Missed discussion of potential test-set contamination in related work"** — Removed as scope creep; this criticism is subsumed by the major weakness on database decontamination.

- **"Qualitative examples are cherry-picked"** — Removed. Qualitative examples in any paper are by nature illustrative; the paper does not make quantitative claims from these examples.

- **Generic category-driven concerns** (e.g., "could the metric be measuring a proxy?") — Removed as speculative with no concrete anchor in the paper.

## Suggestions

1. **Address database decontamination directly.** Report whether any retrieved images overlap with evaluation test sets (via near-duplicate detection or embedding-level similarity to test images). Re-run on a cleaned subset and confirm that results hold. Even a brief analysis showing the overlap rate is negligible would substantially strengthen the paper.

2. **Add error bars** on at least 3 runs for a representative subset of datasets (e.g., ImageNet, FGVC Aircraft, RESISC45) for the main results and the ablation.

3. **Run the ablation on at least one additional dataset** beyond FGVC Aircraft to demonstrate that all components contribute across different data types.

4. **Provide a brief runtime/latency analysis** (time per test image) to help assess practical deployability.

5. **Ablate or justify the use of OT** over simpler aggregation methods (e.g., weighted average).
