## Summary

This paper investigates compositionality failures in CLIP-based text-to-image models, identifying two error sources: (i) erroneous attention contributions in CLIP's text encoder (a minor source), and (ii) sub-optimality of CLIP's output embedding space for compositional prompts (the major source). The authors propose WiCLP (Window-based Compositional Linear Projection), a lightweight learned linear projection applied to CLIP's output embeddings, along with a SWITCH-OFF time-step gating strategy that preserves clean-image FID. The method achieves competitive VQA scores on T2I-CompBench with substantially fewer trainable parameters than fine-tuning baselines.

## Strengths

- **Quantitative isolation of two error sources.** The paper provides direct evidence that CLIP's output space is sub-optimal by optimizing per-prompt text embeddings (c*) via gradient descent on the denoising loss, showing large VQA gains (e.g., 0.3615 → 0.7513 on color). This demonstrates that the UNet *can* generate compositional scenes given a suitable embedding, cleanly attributing a significant portion of the failure to the text encoder's output space rather than the UNet itself. Separately, the attention contribution analysis (cont_{i,j} metric) quantifies erroneous cross-token attention in CLIP vs. T5.

- **Parameter-efficient and empirically competitive method.** WiCLP fine-tunes only a single linear projection (a matrix of dimension (5×768)×768 ≈ 2.95M parameters) while freezing the UNet, CLIP encoder, and VAE. Despite this light footprint, it matches or exceeds GORS (which fine-tunes many more parameters) on color, texture, and shape VQA scores while maintaining a lower FID on MS-COCO (27.40 vs. GORS 30.54). This demonstrates a favorable trade-off between compositionality gain and general image quality.

- **SWITCH-OFF preserves clean accuracy while retaining compositionality gains.** The paper introduces a time-step threshold τ that applies the linear projection only during early denoising steps (t ≥ τ) and reverts to the original CLIP embedding later. Figure 7 shows τ = 800 yields VQA scores nearly as high as full-step application while keeping FID essentially identical to the clean model (~23). This is a practical contribution that addresses a known limitation of fine-tuning approaches.

- **Mechanistic analysis via attention contributions.** The paper defines a precise per-layer metric (cont_{i,j}) to quantify how each token contributes to another token's norm (Equation 4–6). Using this, they show specific failure patterns — e.g., the object token "car" attending more to the wrong attribute "green" than the correct one "red" — going beyond prior correlation-based analyses.

## Weaknesses

### Fatal
None.

### Major

- **Asymmetric attention metric undermines the T5 vs. CLIP quantitative comparison (Section 3.1).** The paper defines "unintended attention" differently for CLIP and T5: for CLIP it counts only cases where o₂ attends more to a₁ than a₂; for T5 it also counts the symmetric case (o₁ attends more to a₂ than a₁). This asymmetry biases the comparison in T5's favor by giving it a broader detection surface. The conclusion that "T5 has significantly lesser erroneous attention contributions than CLIP" is therefore not supported by the presented quantitative evidence at the claimed confidence level. Since the paper later shows that correcting attention errors yields only a 2.93% improvement — and the core contribution (WiCLP) does not depend on this comparison — this weakness does not invalidate the method, but it materially weakens the diagnostic narrative and must be fixed (symmetric metric or removed quantitative claim) before the analysis can be trusted.

- **The "optimal embedding" experiment (Section 4) is an oracle that does not directly validate the linear projection approach.** The paper optimizes per-prompt embeddings c* using the denoising loss on high-quality images selected from three models (SD, DeepFloyd, SynGen). This shows an optimal embedding *exists* for each prompt individually, but it does not demonstrate that a *single global linear projection* trained across all prompts converges to this space. The paper never compares the learned WiCLP embeddings to the per-prompt optimized embeddings (e.g., via cosine similarity or reconstruction loss). The claim that WiCLP "maps [CLIP's] sub-optimal space to an enhanced one" remains empirically plausible but unverified against the oracle. This weakens the causal chain from diagnosis to proposed solution.

### Minor

- **Dataset construction may introduce knowledge distillation confounds.** The training set selects the top-30 VQA-scoring images per prompt from a pool generated by three models (SD v1.4, DeepFloyd, SynGen). DeepFloyd (T5-based) and SynGen are known to have superior compositionality. This means the linear projection is effectively trained to mimic features of stronger models' outputs, not necessarily to correct CLIP-specific deficiencies. The paper does not discuss this limitation or control for it (e.g., by training only on SD-generated images and checking whether gains persist).

- **No variance or confidence intervals for main VQA results.** The reported VQA improvements (16.18%, 15.15%, 9.51% on SD v1.4 color/texture/shape) are stated as point estimates without standard error or variance across prompts or seeds. Given the modest size of the evaluation set (1,000 prompts total), this makes it difficult to assess the statistical reliability of the claimed improvements.

- **Zero-shot attention reweighting is hand-crafted and prompt-type-specific.** The matrix M requires manual specification per prompt type (e.g., knowing which tokens are attributes vs. objects). The 2.93% improvement is modest, which the paper acknowledges, but the method's lack of generality limits its value as a baseline.

- **Ablation on window size is limited.** Only s=2 is used for WiCLP; the comparison is between s=0 (CLP) and s=2 (WiCLP). A systematic sweep (s=0,1,2,3) with VQA/FID trade-offs would strengthen the understanding of how window size affects performance.

## Novel Insights

The reviews surface a useful tension: the paper's diagnostic narrative (asymmetric attention metric + oracle embedding experiment) is substantially weaker than the paper presents, but this weakness is largely orthogonal to the method's empirical success. WiCLP works regardless of whether the T5 comparison is properly calibrated, and the SWITCH-OFF strategy for maintaining FID is independently valuable. The strongest claim the paper can actually defend is that a simple learned projection on CLIP embeddings improves compositionality — the multi-step diagnostic story (attention errors → output space → linear fix) overreaches in places. This suggests the paper would be more credible if it reframed the analysis as suggestive rather than conclusive, and let the method stand on its experimental results.
