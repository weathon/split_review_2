## Summary

This paper presents ChEF, a modular evaluation framework for Multimodal Large Language Models (MLLMs) that decouples evaluation into four components: *Scenario*, *Instruction*, *Inferencer*, and *Metric*. The framework defines six "desiderata" (calibration, in-context learning, instruction following, language performance, robustness, hallucination) with custom recipes and metrics. A large-scale study evaluates 9 MLLMs across 9 scenarios and all six desiderata, yielding several observations about current model capabilities and trade-offs. The paper's strongest empirical contribution is the stability analysis showing that the proposed PPL-based inferencer reduces evaluation variance compared to prior direct-output methods.

## Strengths

1. **Well-designed modular decomposition.** The decoupling into Scenario, Instruction, Inferencer, and Metric (Sections 3.1/5.1) is a genuine architectural contribution. It enables existing benchmarks (MME, MMBench, SEEDBench, LAMM) to be expressed as specific *Recipes*, and facilitates the construction of new evaluations through component recombination. This modularity is concretely demonstrated with two example recipes (Figure 2).

2. **Six clearly defined desiderata with custom metrics.** The paper introduces evaluation dimensions beyond accuracy — calibration (ECE), in-context learning (RIAM), instruction following (Match Ratio), language performance (GPT-based grading), robustness (RRM), and hallucination (POPE-style). Each has a dedicated recipe and metric, and the metrics are designed to isolate the target capability (e.g., RIAM normalizes by accuracy above random guessing to isolate ICL contribution).

3. **Demonstrated reliability improvement via PPL.** The stability analysis (Section 4.3, Figure 4) provides quantitative evidence that the PPL inferencer substantially reduces variance across different query formulations compared to the direct-output methods used by LAMM and LVLM-eHub. This is the paper's strongest empirical contribution and directly supports the claim of more reliable evaluation.

4. **Large-scale multi-model, multi-scenario evaluation.** Table 1 reports 9 models × 9 scenarios, and Figure 5 presents all six desiderata across models. The resulting findings — e.g., that no model performs well across all scenarios, that ICL and instruction following remain challenging — are informative for the community.

5. **Cross-correlation analysis linking desiderata to visual performance.** The Pearson correlation matrix (Figure 6a) reveals that hallucination is strongly correlated with MMBench performance and that instruction following correlates with language performance and robustness, going beyond single-metric reporting to probe intrinsic model properties.

## Weaknesses

### Fatal
None.

### Major

1. **PPL-based evaluation of generative tasks lacks validity evidence.** The default protocol converts generative tasks (captioning on Flickr30k, detection on VOC2012, counting on FSC147) into multi-choice QA by using PPL over a candidate answer pool. This fundamentally changes what is measured: the model's ability to rank pre-selected candidates rather than generate appropriate free-form output. For captioning, negative candidates are retrieved by text similarity; for detection, ground-truth bounding boxes are randomly perturbed to create candidates. The paper provides no validation that PPL-based accuracy correlates with standard metrics (e.g., BLEU/CIDEr for captioning, mAP for generative detection). The stability argument (variance reduction) does not substitute for validity — a measure can be stable yet not measure what it claims to measure. This is stated as a limitation in the Conclusion ("GPT-based evaluation...effectiveness has not been conclusively determined") but the more fundamental concern about PPL-based evaluation of generative tasks is not acknowledged, let alone addressed. The headline results in Table 1 must therefore be interpreted cautiously.

2. **Detection evaluation protocol is highly artificial.** The VOC2012 recipe (Section 5.2, line 301-303) first asks the model to identify the object category via PPL, then asks for a bounding box from a pool generated by randomly scaling/translating the ground-truth box. This two-step PPL process over artificially perturbed GT boxes does not test genuine spatial reasoning or grounding — it tests whether the model can select the correct box among distractors generated from the correct box. Models trained for detection (Shikra, Kosmos-2) may be evaluated on a capability that is only tangentially related to what they were designed to do.

3. **Duplicate sections with an inconsistency undermine presentation quality.** The paper contains two Introduction sections (lines 18 and 72) and two sections describing the ChEF framework (Section 3, line 151, and Section 5, line 264) with overlapping but not identical text. More critically, the VOC2012 recipe's metric is inconsistent across the two versions: the first version (line 160 caption, line 185 text) specifies **mAP**, while the second version (line 274 caption, line 303 text) specifies **Accuracy**, with text explaining the switch to accuracy because detection is transformed into multi-choice QA. A reader cannot determine which version is authoritative without cross-referencing both. This structural issue suggests the paper was assembled from multiple drafts without sufficient editing.

### Minor

4. **No uncertainty estimates in the main results table.** Table 1 reports single accuracy numbers per model per scenario without error bars, confidence intervals, or standard deviations. This is conspicuous given the paper's emphasis on evaluation reliability and the explicit finding that PPL is chosen for its stability across instruction variations. The stability analysis (Figure 4) shows that PPL reduces but does not eliminate variance, yet no variance is reported in the main results.

5. **Novelty claims are slightly overclaimed.** The Abstract states "the first Comprehensive Evaluation Framework" and line 92 claims being "the first to incorporate ICL into the evaluation framework." Prior frameworks (LAMM, LVLM-eHub) are cited but dismissed without a systematic comparison showing how ChEF improves upon them. LAMM already supports few-shot evaluation, so the ICL novelty claim is primarily about naming/formalization. A structured head-to-head comparison would substantiate the novelty claims.

6. **Correlation analysis has limited statistical support.** The Pearson correlations in Figure 6a are computed over only 9 data points (models). The reported correlations (e.g., between hallucination and accuracy) are suggestive but not statistically reliable without confidence intervals or bootstrap estimates. The authors should either report uncertainty or explicitly treat these as exploratory.

### Trivial

7. **The duplicate section structure should be consolidated.** The paper would be significantly cleaner with a single Introduction and a single ChEF framework section. The mAP/Accuracy inconsistency for VOC2012 should be resolved (the second version's "Accuracy" with explanation is the correct one).

## Nice-to-Haves

- A validation experiment comparing PPL-based accuracy with standard metrics (BLEU/CIDEr for captioning, a more natural detection metric) on a subset of scenarios would substantially strengthen the paper's core claims about evaluation validity.
- A direct comparison showing that ChEF yields different (more reliable or more informative) conclusions than LAMM or LVLM-eHub on the same models/tasks would substantiate the claimed improvements.

## Suggestions

1. **Resolve the duplicate sections immediately.** Merge the two Introductions and the two ChEF framework sections into single, coherent expositions. The second versions are generally more polished — use them as the base. Fix the mAP/Accuracy inconsistency for VOC2012 (it should be Accuracy, with the explanation that detection is transformed into multi-choice QA).

2. **Add a validation study for PPL-based evaluation.** For at least one generative scenario (e.g., Flickr30k captioning), compare PPL-based accuracy against standard metrics (BLEU-4, CIDEr, METEOR) on the same model outputs. If the correlation is high, this addresses the core methodological concern.

3. **Report variance in Table 1.** Add standard deviations or confidence intervals (e.g., from multiple instruction formulations or bootstrap resampling) for at least a subset of the main results. This aligns with the paper's own emphasis on evaluation reliability.

4. **Add confidence intervals to the correlation analysis (Figure 6a)** or explicitly state that with N=9 the correlations are exploratory and should not be over-interpreted.

## Score and Decision

The paper makes a genuine contribution — a modular, extensible evaluation framework with well-defined desiderata, supported by a large-scale empirical study and a convincing stability analysis. However, it has two notable weaknesses: (1) the PPL-based evaluation of generative tasks lacks validity evidence, making the headline results harder to interpret than claimed; (2) the duplicate sections and the mAP/Accuracy inconsistency reflect insufficient editorial polish. Neither is fatal; both are fixable. On balance, the paper deserves acceptance subject to addressing the major concerns.
