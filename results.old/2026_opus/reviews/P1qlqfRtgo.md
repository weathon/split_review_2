## Summary
The paper compares three small neural network architectures — a plain MLP, a residual MLP labeled "U-Net," and a "DeepONet-inspired" model — on a single synthetic H₂/O₂/air autoignition dataset generated by a stiff ODE solver. The reported finding is that the residual model achieves an order-of-magnitude lower mean MSE on a held-out test set than the other two, with non-overlapping 95% CIs.

## Strengths
- **Statistically separated mean test MSE.** Table 1 reports non-overlapping 95% CIs between the residual model ([7.69×10⁻⁴, 1.98×10⁻³]) and the MLP / DeepONet baselines (~1.6–2.2×10⁻²), so the within-this-experiment performance gap is real.
- **Recursive multi-step training loss.** Eq. (4) defines a 30-step recursive MSE loss, which is reasonable for an autoregressive ODE-style surrogate and is applied uniformly across all three models.
- **Controlled training protocol across architectures.** Section 4.4 uses the same optimizer (Adam, lr=1e-3), batch size (5,000), epoch count (100), and loss across all three models, eliminating one obvious confound.
- **Physics-informed output constraints.** All architectures copy `dt` and the inert species (N₂, Ar) from input to output (Sections 4.1–4.3), which embeds an exactly-correct invariance rather than asking the network to learn it.

## Weaknesses

### Fatal
None — none of the verifiable issues alone invalidates the empirical observation in Table 1.

### Major

- **The "U-Net" is structurally an MLP with skip connections, and the MLP baseline differs only by removing those skips.** Section 4.2 describes the same hidden widths as Section 4.1 (13→100→120→120→100→13) with a local additive skip across the middle block and a global additive skip from the 13-dim input to the 13-dim output. There is no downsampling/upsampling, no spatial dimension, no convolutional structure — none of the multi-resolution machinery that defines a U-Net. The honest interpretation of Table 1 is therefore "a residual update outperforms a feedforward update for stiff-chemistry state prediction" — a known result in the residual/Neural-ODE literature. The conclusion in Section 5–6 that "hierarchical feature extraction" / "multi-scale representation" causes the improvement is not supported by the actual architecture, which contains no hierarchical or multi-scale machinery. This mislabeling weakens the headline framing of the abstract and Section 1.

- **The DeepONet baseline is not used in the operator-learning regime DeepONet was designed for.** Section 4.3 has the branch take 12 state variables and the trunk take a scalar `dt`, with element-wise/matrix-product fusion. There is no input function being discretized for the branch — it sees a single point — so this is effectively a low-rank bilinear factorization between state and `dt` features rather than an operator-learning model. The paper itself notes (Sec. 1) that Goswami et al. (2024) used the trunk to query future instants, then discards that setup without justification. The cross-family claim in the introduction ("can operator-learning architectures outperform U-Net-style residual networks") is therefore not actually tested.

- **The reported MSE is not anchored to a physically meaningful quantity.** Section 5 reports MSE "in the same normalized space that was used to train the networks," but the normalization scheme is never defined anywhere in Sections 2–4. Per Fig. 1, species concentrations span ~10 orders of magnitude (H₂O ≈ 90 mol/m³ vs. H₂O₂ ≈ 10⁻⁹ mol/m³). Under min-max normalization, total MSE is dominated by the major species, whereas radicals (which actually control ignition delay) are essentially invisible to the metric. Without specifying the normalization and showing a physically meaningful metric (per-species relative error, ignition-delay error, equilibrium error), the comparison cannot support the claim that the model "captures combustion dynamics."

- **Reported variance is across test trajectories, not across training runs.** The "STD" in Table 1 and the 95% CIs measure the spread of MSEs over the test set for a single trained model — not run-to-run variability. With one model per architecture and no seed sweep, the claim that one architecture "consistently outperforms" is not directly supported. Given that the residual model has a built-in inductive bias (parameterizing `x_{t+dt} ≈ x_t + g(·)`), seed-to-seed comparisons would be the natural sanity check.

- **No comparison with existing chemistry-acceleration baselines and no wall-clock measurement.** The motivation (Section 2) is explicitly speed (~90% of CFD time is chemistry), yet no wall-clock comparison with the stiff ODE solver, ISAT (cited as Pope 1997), ChemNet (cited as Ji & Deng 2021), or the Goswami et al. DeepONet (cited) is presented. Without either a speed measurement or a same-task comparison to a prior surrogate, the reader cannot judge whether 1.4×10⁻³ normalized MSE is a useful surrogate or merely better than two weak in-paper baselines.

### Minor
- **Loss weighting decays with rollout step (Eq. 4 uses 1/k).** In stiff-ODE rollouts, late-step error accumulation is typically the central concern, and most schemes weight later steps equally or higher. The 1/k weighting is unjustified and structurally favors any model with an identity-bias path (i.e., the residual model). A brief justification or ablation would help.
- **Non-overlapping CIs are interpreted as architecture-level significance.** Section 5 frames the disjoint CIs as evidence of an architecture-family difference. The disjoint CIs only show that the population test-MSE of these specific trained models differs; with one seed each, they do not show that the architecture family differs.
- **Qualitative robustness is shown on a low-MSE and an upper-quartile case, not on the worst-quartile cases.** Section 5 explicitly says "certain test trajectories remain challenging to approximate" — but Figures 3–4 do not show those trajectories. The worst-quartile examples are the most diagnostic data the paper has.
- **Test set composition relative to ignition events is not characterized.** With `Δt ∈ [10⁻¹⁰, 10⁻⁵] s` sampled across 5 orders of magnitude, the proportion of test samples that actually cross an ignition front is unclear. Since this is precisely the regime the paper says matters, the test-set composition should be described.

### Trivial
- The conclusion language ("multi-scale representation," "hierarchical feature extraction") describes architectural properties the implemented network does not possess; this is presentation cleanup, but it leaks into the technical claim and should be rephrased.

## Nice-to-Haves
- A clean ablation: identical MLP backbone, with and without the global skip, with and without the local skip, at matched parameter count. This single experiment would convert the paper's claim from "U-Net wins" to a defensible "residual skips win."
- A DeepONet baseline in its intended regime (e.g., trunk queries forward time from a fixed `t₀`, as in Goswami et al. 2024).
- Report per-species relative error (log scale for radicals), ignition-delay error, and final-equilibrium error.
- Multi-seed training to separate run-to-run from trajectory-to-trajectory variance.
- Wall-clock comparison against the stiff ODE solver.

- Add the clean three-way ablation (no skip / local skip only / local + global skip) at matched parameter count.
