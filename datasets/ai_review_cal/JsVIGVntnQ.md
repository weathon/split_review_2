## Summary

This paper proposes MLAQ (Model-based LLM Agent with Q-Learning), a framework that integrates Q-learning with LLM-based imaginary interactions to enable optimal decision-making in LLM agents. The key ideas are: (1) using an LLM-based world model and basic policy to generate imaginary transitions for Q-learning without environmental data, (2) a virtual-node UCB variant for exploration/exploitation without environmental tools (with a sub-linear regret bound), and (3) a mixed-examination mechanism (LLM self-checking + environmental correction) to reduce hallucination errors. Experiments on BlocksWorld (single-agent) and RoCo-benchmark (multi-agent) show strong performance, with >90% optimal rates where baseline methods struggle.

## Strengths

1. **Novel integration of tabular Q-learning with LLM-based imagination space.** The paper develops a concrete framework (Q-planner + memory + LLM-based world model) that allows an LLM agent to perform RL optimization purely from imagined transitions, without requiring environmental tools for dynamics, available actions, or reward functions. This is a clean, principled architectural contribution.

2. **Virtual-node UCB variant with regret analysis.** Section 3.2 introduces a selection rule that handles the unknown action-set problem by introducing a virtual node whose confidence bound decays as the known action set grows. Theorem 1 establishes that this variant achieves the same O(log N) regret bound as standard UCB. While the theory is scoped to well-defined Q-values (not the noisy LLM setting), this is the first formal treatment of exploration-exploitation balance in a fully LLM-based imagination space.

3. **Quantified analysis of self-examination error reduction.** Section 4.5 provides concrete metrics: the checker's precision (97.6% for actions, 98.4% for predictions), and calculates that self-examination reduces the probability of storing an erroneous transition from 15.6% to 1.36%. This gives tangible evidence for the mixed-examination mechanism's effectiveness.

4. **Strong empirical performance, especially on long-horizon tasks.** On BlocksWorld, MLAQ achieves >90% optimal rate across all difficulty levels, whereas all baselines (CoT, RAP, Rex, RAFA) succeed only on tasks with ≤6 optimal steps. In the multi-agent Sort domain, MLAQ reduces environmental replans by roughly two orders of magnitude compared to RoCo while maintaining near-100% success rates. The domain memory ablation (Table 4) demonstrably shows cross-task memory reuse is a key enabler.

5. **Iterative optimization demonstration (Section 4.3).** Running MLAQ for multiple epochs with non-empty memory further improves optimal rates and reduces token consumption, showing the framework's ability to refine policies over time.

## Weaknesses

### Fatal

None. The paper's core contribution — integrating Q-learning with LLM-based imagination — is sound. The weaknesses below are significant but addressable.

### Major

1. **Unfair comparison conflates transfer learning with the paper's core claims.** Section 4.1 states: "Within a domain, the experiments are conducted from the tasks with smaller optimal steps to those with larger steps. Consequently, only the memory size of MLAQ would increase gradually with the experiments." This means that when solving a 12-step task, MLAQ already has transitions from 2-, 4-, 6-, 8-, and 10-step tasks in its memory. The baselines (CoT, RAP, Rex, RAFA, RoCo) are given no such cross-task knowledge. The headline performance gap is therefore unsurprising and does not cleanly demonstrate the core methodological claim — it conflates the benefit of Q-learning with the benefit of cumulative task experience. The ablation "MLAQ w/o domain memory" (task-specific scope, 83% on 8-step) partially addresses this, but the main comparison in Table 1 remains structurally skewed. The paper should either (a) report a zero-shot variant where memory is initialized empty for each new task, or (b) give baselines access to equivalent cross-task memory.

2. **No statistical variance reported for any result.** LLM outputs are stochastic, yet all tables (Table 1, 2, 3, 4) report single numbers per condition with no runs, seeds, confidence intervals, or error bars. For a paper claiming >90% optimal rates where baselines get 0%, this is a critical evidential gap. Without variance estimates, the reader cannot assess whether the results are stable or driven by a single favorable run. This undermines the strength of every quantitative claim.

### Minor

1. **The regret theorem (Theorem 1) does not address the actual source of difficulty — LLM hallucination in imaginary transitions.** The bound assumes stationary, correctly estimated Q-values, but in practice, Q-values are computed from imaginary transitions generated by an LLM world model that the paper itself acknowledges hallucinates (Section 4.5: 1.36% erroneous transition rate). The paper provides no analysis of how such errors propagate through Q-learning or how the bound degrades under noisy transitions. The theorem and the empirical algorithm are disconnected.

2. **Missing hyperparameter values for reproducibility.** The paper introduces several parameters (learning rate α, UCB coefficient w, virtual-node parameters w_g and ε_g, discount factor γ, LLM temperature, number of imagination rounds per task) without specifying their values. These are essential for reproducibility.

3. **Self-examination analysis is based on a small sample (128 states) with a suspicious 100% world model accuracy.** A sample of 128 states in the Sort domain is modest for drawing quantitative conclusions about error rates. The reported 100% accuracy for the world model's next-state predictions is unusually high and may indicate that the test states are too simple or that the model has memorized Sort's dynamics. The paper does not discuss why 100% accuracy is plausible or whether it generalizes.

4. **The practical form of the virtual node's confidence bound** \(g(x) = w_g(e^{-\bar{x}^2} - \epsilon_g)\) **is presented without justification or sensitivity analysis.** No ablation studies the impact of w_g or ε_g on exploration behavior or final performance.

5. **No discussion of computational cost.** MLAQ achieves low "Env Replans" but this comes at the cost of many LLM calls per imagination round (basic policy, world model, action checker, prediction checker). A token-cost or wall-clock time comparison with baselines would clarify the practical trade-off.

### Trivial

None beyond the minor issues above.

## Nice-to-Haves

- An analysis of how imaginary transition error rates (0%, 1%, 5%, 10%) affect end-task optimal rate, directly linking the self-examination analysis to downstream performance.
- A discussion of whether error correlation between the world model and the checkers (which share the same LLM) could inflate the calculated error-reduction numbers.

## Novel Insights

The harsh critic's most valuable structural observation is that the experimental design conflates two distinct sources of benefit: Q-learning's policy optimization *within* a task, and cross-task memory accumulation *between* tasks. This is not just a "missing ablation" — it is a conflation of the paper's core methodological claim (Q-learning improves LLM decision-making) with a separate transfer-learning effect. The fact that "MLAQ w/o domain memory" still achieves 83% on 8-step (well above RAP's 47%) suggests the Q-learning component itself has value, but the headline 90%+ numbers cannot be attributed solely to the method without disambiguating these factors. This insight is more specific than the paper's own discussion provides.

## Suggestions

1. **Restructure the main comparison.** Report MLAQ with empty memory per task (truly zero-shot) alongside the current cumulative-memory variant. Report best-performing baselines under both their standard condition and with equivalent access to cross-task transitions. This would cleanly separate the Q-learning contribution from the transfer-learning contribution.

2. **Add multi-run statistics.** Run each condition a minimum of 5 times with different random seeds and report means with standard deviations or confidence intervals. The headline 90%+ rates need to be demonstrably stable.

3. **Provide a concrete analysis of imaginary-error propagation.** A simple experiment: corrupt a controlled fraction of imaginary transitions (e.g., 0%, 1%, 5%, 10%) and measure the effect on optimal rate. This would connect the self-examination analysis (Section 4.5) to end-task performance and clarify whether the current 1.36% error rate is tolerable.

4. **Specify all hyperparameter values** (α, w, w_g, ε_g, γ, LLM temperature, imagination rounds per task) in the main text or a dedicated reproducibility appendix.

5. **Add a token-cost or wall-clock time comparison** with baselines to help practitioners understand the practical trade-off between environmental replans and LLM query cost.
