## Summary

MorphGrower is a conditional VAE that generates neuronal morphologies layer by layer, using sibling branch pairs as the basic generation unit. At inference, the tree structure (branch count, parent-child relationships per layer) is taken from a reference morphology, while the geometry (3D coordinates along those branches) is generated by the model conditioned on the previously generated structure. The method enforces topological validity (only the soma can have >2 outgoing branches), directly addressing a key failure mode of the sole prior learning-based method, MorphVAE. Results on four datasets show consistent improvements over MorphVAE on morphological statistics, a real/fake classifier approaches chance accuracy on MorphGrower outputs (54–63% vs. 81–95% for MorphVAE), and an electrophysiological simulation demonstrates that generated morphologies produce firing patterns close to real ones.

## Strengths

1. **Topological validity enforced by synchronous sibling-branch generation.** By generating branch pairs rather than individual 3D-walks (Section 3.1), the model guarantees that only the soma can have more than two outgoing branches, eliminating the invalid tri-furcations/N-furcations that MorphVAE regularly produces (Section 1). This is a concrete, non-trivial improvement over the baseline.

2. **Conditional generation grounded in two biological priors.** The model separates conditions into local (path from soma, EMA of ancestor branches, Eq. 4–5) and global (tree-structure encoding via branch-level GNN+GRU, Eq. 3), justified by prior work on branch orientation and self-avoidance (Section 3.1). This design is concretely instantiated, and the resulting branch orientations are close to reference values (MASB/MAPS in Table 1).

3. **Consistent outperformance of MorphVAE across four datasets on six morphological metrics.** Table 1 shows MorphGrower (and its soma-free variant) achieves values substantially closer to the *Reference* row than MorphVAE on MBPL, MMED, MMPD, MCTT, MASB, and MAPS. For instance, on RGC, MMPD of MorphGrower is 384.34 vs. 269.92 for MorphVAE (reference: 404.73). MorphVAE's MASB/MAPS cannot be computed at all due to topological invalidity.

4. **Real/fake classifier achieves near-chance accuracy.** Table 2 shows a binary classifier trained on real vs. generated morphologies achieves 54–63% accuracy for MorphGrower (close to chance 50%), versus 81–95% for MorphVAE. This is strong evidence that generated samples are hard to distinguish from real ones in terms of visual/geometric plausibility.

5. **Electrophysiological simulation demonstrates functional plausibility.** Section 4.4 and Table 3 report that simulated recordings on generated morphologies match real recordings with relative errors ≤3.66% (e.g., MMF error 0.60%), and the averaged membrane-potential curves in Figure 3 closely overlap. This provides a neuroscience-relevant validation beyond morphological statistics.

6. **Ablation of soma-branch input confirms core method's strength.** MorphGrower\(^\dagger\) (which generates soma branches via an unconditional VAE rather than providing them directly) still outperforms MorphVAE on nearly all metrics (Table 1), isolating the contribution of the conditional branch-pair generation mechanism.

## Weaknesses

### Fatal
None.

### Major

1. **Reference topology constrains generative scope — the framing overstates generality.** The model generates geometry (branch coordinates) conditioned on a fixed tree structure taken verbatim from a reference morphology. Section 3.3 states: *"a new morphology can be generated by selecting a morphology T from the real sample set and calling our model regressively based on the tree structure of T"* and *"the reference branch pairs on the i-th layer on T and the generated previous i-1 layers will be taken as the model input."* While this is transparent, the paper's persistent framing — *"mimicking the neuron natural growth mechanism,"* *"progressive generation,"* *"diverse morphology generation"* — implies that the model discovers both topology and geometry. The title and abstract do not qualify that only geometry is generated within a borrowed topology. The limitations section (Lines 401–402) misses this point entirely, instead listing only missing diameter and asynchronous growth. This framing mismatch is significant because a reader expecting a full generative model will find the method's generative scope is narrower than advertised. **Why it matters:** A weaker framing (e.g., "conditional branch-shape generator given a reference tree structure") would more honestly reflect the method's capabilities, and the evaluation would be better interpreted in light of this constraint.

2. **Missing MorphVAE comparison in the electrophysiological simulation.** Table 3 and Figure 5 compare MorphGrower-generated morphologies against real ones, reporting relative errors of 0.60–3.66%. The paper interprets this as demonstrating *"the plausibility of the morphologies generated by our method from a neuroscience perspective"* (Section 4.4). However, without running the same simulation on MorphVAE outputs, it is impossible to know whether this result is unique to MorphGrower or whether any method that produces reasonable branch shapes would pass this test. Given that the abstract's headline claim is that MorphGrower outperforms MorphVAE, the simulation experiment needs to compare both methods. The paper says simulation is time-consuming (Section 4.4), but a focused comparison on one dataset (VPM, where it was already run) would be sufficient. This is the single largest evidential gap for one of the paper's key claims.

3. **No evaluation of diversity, despite the title claiming it.** The word "diverse" appears in the title but nowhere in the paper body. There is no quantitative diversity metric, no analysis of variance across generated samples, no discussion of how many distinct shape families the model can produce, and no measure of whether repeated sampling from the vMF latent distribution yields meaningfully different outputs. The method does sample latent variables stochastically (Section 3.2), so diversity presumably exists, but it is never measured. For a method whose title promises "diverse generation," this omission is significant.

### Minor

1. **Hyperparameters L (resampling points) and α (EMA) are not reported.** The resampling operation in Section 3.2 rebuilds branches with *"L new node coordinates"* but L is never numerically specified. The EMA hyperparameter α (Eq. 5) is described as a hyperparameter with range [0,1] but its actual value is not given. These are needed for reproducibility.

2. **Limitations section omits the topology constraint.** The Limitations paragraph (Section 5) discusses missing diameter information and asynchronous growth, but does not acknowledge that the method requires a reference morphology's complete tree structure, meaning it cannot generate novel branching patterns. This is an omission in intellectual honesty.

3. **Statistical significance not assessed.** Metrics include standard error, but there are no formal significance tests (e.g., bootstrapped confidence intervals, paired tests) between MorphGrower and MorphVAE. Given the relatively small number of independent runs, this would strengthen the conclusions.

### Trivial

None.

The main novel insight from synthesis is that this constraint is less of a methodological flaw and more of a framing/positioning problem: the paper's technical contribution (topologically-valid, conditionally-generated branch geometry within a given tree structure) is solid, but it is marketed under a broader banner. ## Suggestions

1. **Reframe the contribution clearly.** Adjust the title or abstract to specify that the method generates *geometry* conditioned on a reference tree structure, e.g., "Conditional Branch-Shape Generation for Plausible Neuronal Morphologies" or add a clarifying phrase like "with tree structure from reference morphologies."
2. **Run MorphVAE through the electrophysiological simulation on at least the VPM dataset to complete the comparison.** This is essential to support the claim of neuroscience-level plausibility.
3. **Add a diversity analysis.** Measure the variance of branch lengths, angles, and path distances across multiple samples from the same reference, and report how many distinct shape families emerge. Even limited shape diversity should be quantified.
4. **Report numerical values for L and α** in a table or footnote.
5. **Add significance tests** (bootstrap confidence intervals or paired tests) for the key comparisons in Tables 1 and 2.
6. **Update the limitations section** to explicitly state the dependence on reference tree structure.
