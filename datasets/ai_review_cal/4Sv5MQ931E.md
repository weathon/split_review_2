## Summary

MSR-ViR proposes a modular VideoQA framework where a question parser LLM generates explicit execution policies (reasoning paths), a MoST-Grounding module invokes off-the-shelf detectors (UniVTG, YOLO-World) to localize relevant temporal segments and spatial regions, and a multimodal LLM consumes both grounded evidence and a global video representation to produce answers. A key technical novelty is an alternating self-reflection training strategy: the multimodal LLM undergoes SFT while the question parser is refined via DPO, using the MLLM's loss as a preference signal. Experiments on NExT-QA, STAR-sub, and NExT-GQA show improvements over direct baselines and comparable methods, with ablations validating each component.

## Strengths

- **Interpretable reasoning path via modular policies**: The question parser generates execution policies in structured JSON format (Figure 3), providing a transparent decomposition of the question into sub-steps. This is a genuine architectural advantage over black-box end-to-end MLLMs, and Figure 4 qualitatively demonstrates that the policy decomposes complex questions (e.g., "Why does the man have to squat down after the car approaches?") into grounded sub-tasks.

- **Alternate Self-reflection Training is empirically validated**: Table 3 shows that removing self-reflection reduces NExT-QA accuracy by 1.5 and degrades grounding quality on NExT-GQA. This provides direct causal evidence that the DPO-based feedback loop refines the question parser's policies, supporting the claim that both LLMs are jointly optimized in a meaningful way.

- **Both temporal and spatial grounding contribute**: Ablation in Table 3 ("w/o spatial modules") drops NExT-QA average accuracy by 1.4, confirming that spatial grounding via YOLO-World adds value beyond temporal localization alone. On NExT-GQA, MSR-ViR achieves the best mIoP (MSR-ViR_Q) and mIoU (MSR-ViR_L) among comparable methods, outperforming prior grounding-based approaches that only use temporal localization (e.g., LSTP, SeViLa).

- **Comprehensive grounding evaluation**: Using NExT-GQA's metrics (mIoP, mIoU, Acc@GQA) and disentangling answer accuracy from grounding accuracy is good practice, and the method performs competitively on all three.

- **Empirically validated design choices**: Ablations confirm that both the global video representation and the guiding prompt individually improve accuracy ("w/o global repr." and "w/o instruction prompt" both cause drops), demonstrating that these are non-redundant, well-motivated components.

## Weaknesses

### Fatal
None.

### Major

1. **DPO policy pair generation is underspecified, harming reproducibility of the core training contribution.** The paper states (line 122): "We prompt the question parser LLM to view the same question from multiple perspectives, generating different modular policies." This is the only description of how positive/negative policy pairs are produced for DPO training. Several critical details are missing: (a) how "multiple perspectives" are elicited — is it temperature sampling from a single prompt, multiple different prompts, or some other mechanism? (b) how many candidates are sampled per question? (c) is there any filtering to ensure candidates are executable and distinct? (d) since the MLLM's loss serves as the reward proxy but the MLLM is being trained concurrently, is there any analysis of the stability of this reward signal across alternating training cycles? The DPO component is the most novel training contribution, and without these details the procedure is not reproducible and the claimed benefit cannot be properly assessed.

2. **Interpretability is claimed as a primary advantage but never quantitatively evaluated.** The paper repeatedly motivates the framework by the interpretability gap of end-to-end methods (abstract, Section 1, Section 2), and claims that the execution policies "serve as a reasoning path from questions to answers providing interpretability" (line 4). However, the experiments only measure answer accuracy (VideoQA) and temporal grounding accuracy (IoU/IoP on NExT-GQA). There is no quantitative evaluation of the policies themselves: no human judgment study, no automatic metric for policy correctness, coherence, or faithfulness to the question, and no analysis of whether the reasoning paths are actually useful for understanding the model's behavior. A core advertised benefit remains unsupported by evidence.

### Minor

3. **Spatial grounding input format is not fully specified.** The paper mentions that the spatial localizer generates "most relevant visual bounding box" (line 61) and refers to "spatial-grounded frames" (line 142), but does not explicitly state whether the multimodal LLM receives cropped image patches (rendered into visual tokens), bounding box coordinates as text, or some combination. The number of frames sampled from spatial grounding is given (2 for MSR-ViR_Q, 8 for MSR-ViR_L), but it is unclear how multiple bounding boxes within a frame are handled (e.g., selection, aggregation). This is important for reproducibility.

4. **Global video representation fusion mechanism is underspecified.** The paper describes average pooling along the temporal dimension of encoded video frames to create a compressed global representation (line 91), but does not specify (a) how many frames are sampled for this global representation, (b) how the pooled representation is tokenized or otherwise integrated with the grounded visual tokens (e.g., concatenation in the visual token sequence, addition to the visual embedding, or some other mechanism). The ablation confirms this component helps, but the technical detail is insufficient for reproduction.

5. **No results reported on the full STAR dataset.** The authors create STAR-sub (82.5% of STAR) by excluding Prediction and Feasibility questions, which is justified since those types lack temporal/spatial grounding. However, reporting results on full STAR (even via a fallback strategy for excluded types) would strengthen generality and allow direct comparison with methods evaluated on the full benchmark.

6. **No variance or significance reporting.** Given the alternating training procedure (which could introduce instability), reporting results across multiple seeds or providing confidence intervals would increase confidence in the reported improvements, though single-run evaluation is standard in this area.

### Trivial

7. **The guiding prompt for the MLLM answerer is described but its full content is not provided.** The paper references a "guiding prompt that explains the specific meanings of various visual input components" (line 92) but does not show its content. Including it in an appendix would aid reproducibility.

8. **The exact number of frames used for the global video representation is not stated** (line 91 only says "several frames").

## Nice-to-Haves

- **Computational cost analysis**: MSR-ViR cascades a question parser LLM (Qwen2-7B), UniVTG, YOLO-World, and a multimodal LLM. A comparison of inference time and memory with end-to-end baselines would clarify practical trade-offs.
- **Failure analysis**: A qualitative discussion of cases where off-the-shelf modules (UniVTG, YOLO-World) fail and how the system degrades would add useful depth.
- **Policy correctness metric**: An automatic evaluation of whether generated policies correctly decompose the question (e.g., matching human-annotated reasoning steps if available, or measuring policy diversity).

## Suggestions

1. **Precisely specify the DPO policy pair generation**: Describe the exact prompting strategy for generating diverse candidate policies, the number of candidates per question, any filtering rules, and how positive/negative pairs are selected. A sensitivity study of candidate count or generation temperature would further strengthen the evidence.

2. **Add a quantitative interpretability evaluation**: At minimum, conduct a human evaluation (e.g., raters judge whether policies are coherent, follow a logical sequence, and match the question's intent) or an automatic metric (e.g., policy plausibility, correct sub-step decomposition where annotated data exists).

3. **Clarify the spatial grounding input format**: Explicitly state whether cropped image patches, bounding box coordinates, or both are fed to the MLLM, and describe the tokenization/selection strategy for multiple boxes per frame.

4. **Specify the global representation details**: State the number of uniformly sampled frames used for the average-pooled global representation and how it is fused with the tokenized grounded inputs.

5. **Include results on full STAR** (even via a fallback for Prediction/Feasibility types) to demonstrate generality and enable direct comparison with the broader literature.
