## Summary

This paper introduces the Graphical Multioutput Gaussian Process (GMOGP), which replaces the symmetric covariance structure of classic LMC-based MOGPs with an attention-based directed graphical model. Each output is modeled as a GP whose kernel is a weighted sum of kernels from other (parent) outputs, where parent assignments are learned through a modified attention mechanism. The framework also extends to non-Gaussian data via element-wise normalizing flows (TGMOGP). The key empirical contribution is consistent improvement over baselines (LMC, FICM, GPRN, CMOGP, V-LMC, SGPRN) on synthetic and real datasets, with lower computational cost (reducing from O((SN)³) to O(SN³)) and interpretable learned attention coefficients that match expected dependencies.

---

## Strengths

- **Attention-based asymmetric dependence learning**: The scoring function (Eq. 18) learns asymmetric attention coefficients α_{i,j} that encode directed graphical relationships between outputs. This is empirically validated in Table 3, where the learned coefficients (α_{2,4}=0.8978, α_{3,4}=0.9998) align with high Pearson correlations (0.7744, 0.9657), demonstrating interpretable structure learning that goes beyond the symmetric covariance of LMC-based models.

- **Computational efficiency from separable training**: By reformulating hyperparameter learning as per-output optimization (each output uses an N×N kernel matrix instead of the full SN×SN matrix of standard MOGPs), the complexity reduces from O((SN)³) to O(SN³). Remark 3.2 correctly identifies that no block-diagonal approximations or prediction fusion methods are needed — a genuine advantage over classic distributed GP approaches.

- **Flexible non-Gaussian extension via flows**: Section 3.4 introduces the TGMOGP, applying element-wise invertible transformations (e.g., SAL flow) independently per output. This is concretely validated by Figure 5(c), where TGMOGP substantially outperforms other methods on the sinh-arcsinh-transformed output, and by Table 2 where TGMOGP₁₀₀ matches or exceeds full-data MOGP baselines on real-world skewed data (SARCOS) with lower time cost.

- **Interpretable graphical output structure**: The learned attention coefficients provide explicit directed relationships among outputs (Table 3), going beyond standard MOGP "black-box" covariance matrices by offering readable directional dependencies that can be validated against domain knowledge.

## Weaknesses

### Fatal
None.

### Major

1. **The model is not a proper joint multi-output GP despite the framing.**  
   The paper claims to introduce a "graphical multi-output Gaussian process" that defines dependent processes, but Eq. (14) factorizes the joint distribution only for one specific choice of target node *i*:  
   *p*(*f*⁽¹⁾,...,*f*⁽⁵⁾) = *p*(*f*⁽ⁱ⁾|paᵢ) ∏_{j∈paᵢ} *p*(*f*⁽ʲ⁾).  
   The paper never specifies a consistent joint distribution (a DAG with a topological ordering) over all S outputs simultaneously. Cross-covariances between different outputs are never defined — the model cannot produce a joint predictive distribution across outputs. During inference, each output is predicted independently using its own marginal GP kernel *k*_G⁽ⁱ⁾(X,X) = ∑αᵢⱼ²k_θⱼ(X,X) + k_θᵢ(X,X).  

   What the paper actually delivers is a set of S separate GPs whose kernels are constructed from weighted sums of each other's kernels, not a true joint MOGP with structured cross-covariances. The abstract's claim of "providing dependent processes with attention-based graphical representations" is an overstatement. The individual models are still valid GPs and the empirical results remain useful, but the core theoretical framing does not match what is delivered.

### Minor

1. **Attention-based graph construction uses output labels without sufficient justification.**  
   Section 3.2 states: "In practice, we substitute the observation values ⟨y⁽ⁱ⁾, y⁽ʲ⁾⟩ at the initial learning phase." The scoring function Eq. (18) is defined over latent functions *f*⁽ⁱ⁾, *f*⁽ʲ⁾ but these are replaced by noisy observations *y*⁽ⁱ⁾, *y*⁽ʲ⁾ without justification of why this substitution is valid or what effect the observation noise has on the learned graph structure. Furthermore, the paper does not explicitly state whether the initialization is restricted to training labels only, which would be important for ruling out information leakage.

2. **Training procedure ambiguity.**  
   Section 3.3 first describes per-output optimization ("the parameters corresponding to the i-th output... can be updated via minimizing" Eq. 19), then introduces a joint multi-objective optimization formulation (weighted sum of all outputs' NLLs). It is unclear whether optimization proceeds sequentially per output, as a single global objective, or a combination of both. The shared hyperparameters Θ appear in each output's objective, but the paper does not specify how updates to Θ are coordinated across outputs.

3. **No ablation study of the graph/attention component.**  
   The experiments never compare GMOGP against a version with all parents included (no attention pruning), against equal α weights, or against independent GP models with comparable kernel capacity. Without these ablations, it is impossible to attribute the reported gains to the graphical structure / attention mechanism versus the increased flexibility from having more kernel parameters. The synthetic data generation (Eq. 21) constructs outputs as linear and nonlinear combinations of the same underlying functions, closely matching the GMOGP's own kernel structure — strong performance here is expected and does not demonstrate generalisation to arbitrary dependency structures.

4. **Uncertainty calibration is not evaluated.**  
   Although NLL is reported, the paper does not assess the calibration or coverage of predictive intervals. For a GP-based method, evaluating whether the predictive uncertainties are well-calibrated (e.g., via reliability diagrams or empirical coverage at specified confidence levels) would significantly strengthen the contribution.

### Trivial
1. Results are reported as point estimates without standard errors, confidence intervals, or significance tests. While single-run evaluation is common in this setting, the absence of any variance estimates makes it difficult to assess the stability of reported improvements.

2. Figure/table images are not accessible in the text extraction — this is a formatting issue in the extraction process rather than a paper flaw, but the paper would benefit from ensuring tabular results are machine-readable in the submission format.

## Nice-to-Haves
- An ablation isolating the effect of the attention-based parent selection (e.g., fixed all-parents graph vs. attention graph vs. independent GPs).
- Wall-clock timing breakdown and memory benchmarks against a standard full MOGP on a moderate-sized problem to substantiate the claimed scalability advantages.
- Validation that the learned graph structure matches known domain dependencies on real datasets (beyond Pearson correlation).
- Analysis of how the label-based attention initialization affects downstream performance (e.g., sensitivity to noise level).

## Removed Points

These points were raised in the reviews but are excluded from the main assessment:

- **"Pareto optimal claims are vacuous; weighted sum only works for convex objectives."** — Factually incorrect. Minimizing a weighted sum with strictly positive weights yields a Pareto optimal point regardless of convexity (standard multi-objective optimization result, correctly cited as Marler & Arora 2010). The convexity condition is required for the *converse* (generating all Pareto points), not for sufficiency. This criticism is removed.

- **"Baselines are outdated."** — The paper includes recent baselines: LMC (de Wolff et al., 2021), V-LMC, SGPRN (Li et al., 2021). Classic baselines (FICM 2007, GPRN 2012, CMOGP 2011) are standard in the GP literature. The chronological range is typical for a methods paper. This criticism is removed.

- **"GMOGP prior is already covered by LMC with diagonal coregionalisation matrices."** — Inaccurate. LMC with diagonal coregionalisation gives the *same* kernel structure for all outputs (same latent processes, different weights). GMOGP allows each output to have a *different* parent set and *different* parent-specific kernel functions, enabling asymmetric and output-specific kernel construction. This criticism is removed.

- **"Notational inconsistencies and poorly explained derivations"** (as a general claim). — Too vague to evaluate. Removed.

- **"Proposition 3.1 is stated without proof."** — The proposition follows directly from standard GP properties (linearity of expectation, covariance of sum of independent GPs). Does not weaken the paper. Removed.

- **Missing appendix / proofs in appendix.** — The parser strips these sections. They exist in the original submission. Removed per instructions.

- **Various formatting/style nitpicks.** — Parser artifacts, not author errors. Removed.

## Novel Insights

Neither reviewer contribution surfaces a genuinely novel observation beyond the paper's own contributions. The paper's novel idea — constructing each output's GP kernel as an attention-weighted sum of parent-output kernels, enabling asymmetric dependence and separable training — stands as its own contribution.

## Suggestions

1. **Reframe the contribution accurately.** Replace "graphical multi-output Gaussian process" framing with a more precise description (e.g., "attention-based kernel construction for multi-output regression" or "graph-structured GP priors for individual outputs"). Clarify that the model produces valid marginal GP priors for each output rather than a single joint GP over all outputs.

2. **Add an ablation study.** Compare GMOGP against: (a) all-parent version (no attention pruning, all αⱼ>0), (b) symmetric-α version (α_{i,j}=α_{j,i}), (c) independent GPs with the same per-output kernel capacity. This would isolate the value of the graphical and attention components.

3. **Clarify the training procedure.** State explicitly whether optimization uses a single weighted-sum objective over all outputs or alternates per output, and how shared Θ updates are coordinated.

4. **Justify or replace the label-based attention initialization.** Either provide a theoretical justification for using ⟨y⁽ⁱ⁾, y⁽ʲ⁾⟩ as a proxy for ⟨f_X⁽ⁱ⁾, f_X⁽ʲ⁾⟩, or discuss the limitations and potential biases introduced by this substitution. Clarify that only training labels are used.

5. **Add uncertainty calibration evaluation.** Report empirical coverage of 95% predictive intervals or show reliability diagrams for at least one dataset, leveraging the GP's uncertainty quantification.
