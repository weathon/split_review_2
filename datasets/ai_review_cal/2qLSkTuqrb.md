## Summary

This paper presents a framework that translates cognitive reinforcement learning models of multi-agent foraging behavior into a biologically plausible neural network (based on successor representations) and an equivalent Bayesian statistical model where predictors correspond to components of the agent's value function. The framework is tested on synthetic data (recovering value-function coefficients for hungry/follower/random agents), a communication analysis across environments, a brief application to published locust data, and new thermal+RGB video recordings of ducks and sparrows/titmice where species-specific proximity preferences are inferred. The core contribution is the conceptual integration of these three descriptive levels into a common analytical toolkit.

## Strengths

- **End-to-end mapping from cognitive value functions to neural network layers and statistical predictors.** The paper constructs a complete chain: successor representation (N2) → value computation (N3) → winner-take-all action selection (N4), with each component linked to specific brain areas (hippocampus, motor circuits) and statistical model terms (Section 2.1, Figure 1). This provides a concrete, mechanistic bridge between abstract cognitive variables and observable movement statistics, going beyond prior theoretical connections by specifying a full forward pass.

- **Bayesian inference recovers distinct value-function components from simulated trajectories.** Using simulated hungry (food-valued), follower (proximity-valued), and random agents, the statistical model with food-trace and proximity predictors yields clearly separated posterior coefficient distributions (Figure 2, bottom right). This demonstrates that the method can disambiguate what different agents value from behavioral data alone — a nontrivial inverse inference task.

- **Communication benefits quantified across environments with varying food clustering.** The paper simulates groups with different communication parameters and patch sizes, showing that communication reduces time to first food across all tested environments and that this negative relationship is recoverable via SVI (Figure 3, right). This extends the framework to multi-agent information sharing and demonstrates that environmental structure (patch size) interacts with communication benefit.

- **New multi-species bird dataset with thermal+RGB recording and species-specific proximity preferences.** The paper collects new video data (Section 2.3.2, Figure 4) using combined thermal and RGB imaging to track foraging birds in an outdoor winter setting — a non-trivial data acquisition effort. The fitted models show different peak proximity preferences for ducks (40 pixels) versus sparrows/titmice (30 pixels), consistent with empirical inter-bird distance histograms, demonstrating the framework's applicability to real-world multi-agent trajectory data.

## Weaknesses

### Fatal
None. The core framework and synthetic validation are sound; the weaknesses are in the strength of empirical support, not in the method itself.

### Major

- **The real-world data analyses are critically underdeveloped relative to the paper's framing.** Two specific problems:
  - *Locust analysis (Section 2.3.1):* This subsection contains only three sentences with zero quantitative results — no posterior coefficients, no model comparisons, no figure. The paper claims the method "could identify the use of social information" and "capture a relatively rich real world behavior," but provides no evidence that it did. This is not a valid test; it is an assertion.
  - *Bird data analysis (Section 2.3.2):* The analysis rests on two short video recordings (exact duration and number of individuals not specified). The inference that ducks prefer 40 pixels while sparrows/titmice prefer 30 pixels is presented without formal statistical comparison (no test for whether the difference is significant), without error bars or credible intervals discussed in the text, and without replication. The paper acknowledges "more data is necessary" and calls these "proof-of-concept analyses," but the Abstract presents them as a finding ("Our method distinguishes between proximity preferences..."), creating an expectation gap.

  Since the paper's title emphasizes "real-world multi-agent foraging behavior," the thinness of the real-world validation is a significant weakness. A substantially strengthened version would need either quantitative locust results with baselines, or a bird analysis with sufficient data, formal species comparisons, and uncertainty reporting.

- **No comparison against alternative or simpler models.** The synthetic experiments (Section 2.2.1) recover parameters from data generated by the same model used for inference — a self-consistency check, not a validation against alternatives. The paper does not compare against simpler baselines (e.g., a model using only the uniform-movement baseline, a model using raw nearest-neighbor distance instead of the proximity score, a logistic regression on discrete choices, or a random walk model). Without such comparisons, the reader cannot judge whether the Bayesian model actually captures foraging behavior better than trivial alternatives, or whether the inferred coefficients are reliable. This also means the paper does not test robustness to model misspecification (e.g., agents using softmax instead of argmax, agents with memory-limited policies).

### Minor

- **Model specification is insufficient for full reproducibility.** Several crucial details are missing: (1) the exact likelihood for the response variable is unclear — the text says "raw standard deviation is modeled linearly... and then passed through a softmax function," which conflates a Gaussian-like description with a multinomial outcome; (2) the priors for the Bayesian model are not specified; (3) the "proximity score," "food trace," and "communication" predictors are not defined mathematically — they are described only by example (Figure 2) and high-level prose; (4) for the bird dataset, the video duration, number of birds tracked, frame rate, and number of decisions are not reported. These omissions limit reproducibility and make it hard to assess the reliability of the estimates.

- **Confusing sentence about the communication coefficient in Section 2.2.2.** Line 112 states: "The model correctly assigns near-zero weight (c) to the communication term for simulations with non-zero values for the communication parameter, but not for simulations with zero values of the communication parameter." This appears to say the model assigns ~0 weight to c when the simulation has communication (non-zero parameter), which contradicts Figure 3 center (which shows communicators having non-zero c, non-communicators having near-zero c). The intended meaning is likely the reverse. This needs correction.

- **Claims of "biologically plausible" neural network are somewhat overstated.** The paper acknowledges that the network uses linear successor representations, one-hot state encoding, and winner-take-all argmax (Section 2.1.2) — all "idealized abstractions" of actual neural circuits. Calling this network "biologically plausible" without explicitly tempering the claim is misleading, especially for readers unfamiliar with the gap between these abstractions and biological neural circuitry. The paper would benefit from a clearer statement of what is and is not being claimed about biological realism.

### Trivial

- The locust subsection (Section 2.3.1) is only three sentences long; even as a brief illustration, it needs quantitative support to be meaningful.
- The discussion in Section 2.3.2 mentions "added explanatory power" for the fitted model relative to empirical distance histograms, but this claim is not quantified.

## Nice-to-Haves

- Adding a model misspecification study (e.g., simulating agents with softmax policies, epsilon-greedy exploration, or unobserved state variables) and showing whether the Bayesian model still recovers qualitative patterns would substantially strengthen the claim that the method is robust enough for real-world application.
- Reporting formal model comparison (WAIC or cross-validated log-likelihood) for the bird data across different preferred-proximity settings, rather than only reporting which setting gave the largest coefficient.
- Including more bird video recordings (even 3–4 per species) to enable statistical testing of the species difference.
- Clarifying the model likelihood (Gaussian? Multinomial? Bernoulli on step directions?) and reporting priors explicitly in the main text or a supplement.

## Suggestions

1. **Strengthen the real-world validation.** Either (a) provide quantitative locust results — posterior coefficients, model comparison against a null model, a figure — or remove the subsection entirely. For the bird data, include replicate recordings per species (even 3–4 each), report credible intervals for all coefficient estimates, and run a formal model comparison (WAIC or cross-validated log-likelihood) to test whether the species difference is supported.

2. **Add baseline comparisons on synthetic data.** Compare the Bayesian model against simpler alternatives: a baseline-only model (no predictors), a model using raw nearest-neighbor distance instead of the proximity score, and a model using only one predictor at a time. Show that the full model outperforms these on held-out prediction or parameter recovery.

3. **Test robustness to model misspecification.** Simulate agents that use softmax instead of argmax, agents with epsilon-greedy exploration, or agents whose preferences change over time. Show that the Bayesian model still recovers the correct qualitative patterns despite being fit with the wrong generative model.

4. **Fully specify the statistical model.** Report: the exact likelihood (what distribution is used for the response?); the priors for all coefficients; mathematical definitions of proximity score, food trace, and communication predictors; and bird-data acquisition details (duration, frame rate, number of individuals tracked, total number of decisions).

5. **Correct the confusing sentence in Section 2.2.2** about communication coefficient assignment.

6. **Tone down or qualify the "biologically plausible" claims** by explicitly stating which aspects are acknowledged abstractions (one-hot encoding, linear successor representation, winner-take-all argmax) and why they are still useful approximations.
