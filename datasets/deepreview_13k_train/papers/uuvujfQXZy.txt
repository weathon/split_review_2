\title{Selective Concept Bottleneck Models Without Predefined Concepts}

\begin{abstract}
There has been considerable recent interest in interpretable concept-based models such as Concept Bottleneck Models (CBMs), which first predict human-interpretable concepts and then map them to output classes. To reduce reliance on human-annotated concepts, recent works have converted pretrained black-box models into interpretable CBMs post-hoc. However, these approaches predefine a set of concepts, assuming which concepts a black-box model encodes in its representations. In this work, we eliminate this assumption by leveraging unsupervised concept discovery to automatically extract concepts without human annotations or a predefined set of concepts. We further introduce an input-dependent concept selection mechanism that ensures only a small subset of concepts is used across all classes. We show that our approach improves downstream performance and narrows the performance gap to black-box models, while using significantly fewer concepts in the classification. Finally, we demonstrate how large vision-language models can intervene on the final model weights to correct model errors.

\end{abstract}

\section{Introduction}



Deep neural networks have achieved tremendous success in a wide range of tasks and modalities, such as vision and natural language. However, they are \emph{black-box} models, making it difficult for humans to understand and comprehend their decisions.
Thus, there has been a profound recent interest in developing \emph{interpretable} models. One popular framework are Concept Bottleneck Models (CBMs) \citep{koh2020concept}, \ie, models that first predicts human-interpretable concepts and then use these concepts to predict the classes \citep{lampert2009learning,kumar2009attribute}. 
CBMs are trained in an end-to-end fashion through supervision on \emph{both} the concepts and classes.
However, the need for human-annotated concepts during model training requires time-consuming and expensive collection of such annotations.

To address the above limitation of supervised CBMs, recent work \citep{yuksekgonul2023posthoc,oikarinen2023labelfree,marcinkevivcs2024beyond} has converted pretrained, black-box models into CBMs in a \emph{post-hoc} fashion.
These works either learned linear probes on human-annotated concepts or used vision-language text features to align a black-box model's activations with human-interpretable concepts.
Note that the linear probing approach still requires human-annotated concepts, but they are only needed during the conversion stage.
However, a crucial assumption underlies all the aforementioned approaches: it is implicitly assumed that the predefined concepts are encoded by some pretrained, black-box model. 
But
\begin{center}
    \emph{how can we determine a priori which concepts some pretrained, black-box model encodes?}
\end{center}

To eliminate this assumption, we propose to extract concepts in an \emph{unsupervised} manner instead.
Specifically, we draw from the rich literature on unsupervised concept discovery \citep{ghorbani2019towards,zhang2021invertible,zou2023transparency,fel2023craft,vielhaben2023multidimensional,fel2023holistic,huben2024sparse,stein2024towards}. The main idea of these approaches is to find a (small) set of concepts that faithfully represents a model's activations. \citet{fel2023holistic} has shown that many of these approaches can be seen as an instance of the dictionary learning problem \citep{dumitrescu2018dictionary}. That is, these approaches aim to find a dictionary matrix (\ie, a dictionary of concepts) that defines the (concept) basis vectors while the sparse coefficient matrix weighs these basis vectors.
After learning such a dictionary matrix, we propose to project a black-box model's representation onto the space spanned by the concept basis vectors of this dictionary matrix.
It is important to observe that there is no need for human-annotated concepts nor to predefine concepts a priori. Instead, we effectively shift the concept selection step to after the concept discovery.

After constructing the (concept) space spanned by the human-interpretable concepts, we use a sparse linear model to map from that space to the class output space. Following previous work \citep{yuksekgonul2023posthoc,oikarinen2023labelfree}, we apply sparsity to the weights of the linear layer. This results in a sparsity \emph{per-class}, \ie, the decision for a class relies only a small set of concepts.
However, we found that it overlooks the number of concepts used \emph{across all classes}. For example, while class $i$ may not use concept $k$, another class $j$ might use it for a given input sample. Consequently, there are many more concepts (typically $\geq 90\%$ of the available concepts) that influence the entire classification.
If a concept should not be used in classification, either its projection needs to be zero, or the column vector for that concept needs to be the null vector. We typically did not observe the former. Note that the latter is \emph{input-independent} and, thus, effectively reduces the number of concepts and as a result downstream performance (\cref{fig:concepts_vs_performance} shows the relation between both).

To address this challenge, we propose a simple \emph{input-dependent concept selection mechanism} that enforces additional sparsity on the number of concepts used across all classes. Technically, we employ a gating mechanism that selectively removes concepts, retaining only a sparse set of them per input. To enforce sparsity on the number of concepts used, we apply a sparsity regularization to the output of the gating mechanism. It is important to observe that this mechanism is \emph{dynamic}, meaning the concepts that are removed or retained are input-dependent.

Our contributions are as follows:
\begin{itemize}
    \item We propose a novel method (\cref{fig:method_overview}), which we dub Unsupervised Concept Bottleneck Models (UCBMs), as it converts any pretrained model into a concept-based model \emph{without} requiring human-annotated concepts or predefining the set of concepts. This allows \ours to freely find concepts that most faithfully represent the activations of the pretrained black-box model.
    \item Further, we propose a novel input-dependent concept selection mechanism. It retains a sparse set of concepts, thereby substantially increasing the sparsity across all output classes. For example, as few as ca. $0.7\%$ of the available concepts are used per input (see \cref{tab:sparsity}).
    \item Our experiments show that \ours can further close the gap to their black-box counterparts, while having a substantially higher degree of sparsity.
    \item Lastly, we showcase a novel way of utilizing large language-vision models to inform model editing.
\end{itemize}


\section{Unsupervised Concept Bottleneck Models}

\begin{figure}[t]
    \centering
    \includegraphics[width=1\textwidth]{figures/method_overview/method_overview.pdf}
    \caption{\textbf{Overview of \ours.} In the first step (top), we extract concepts (represented as normalized vectors) using an unsupervised concept discovery method. Given an input sample, we project the activations on the space spanned by these concept vectors (middle at the bottom). Finally, we train an interpretable classifier consisting of an input-dependent concept selection mechanism and sparse linear layer (middle to right at the bottom).}
    \label{fig:method_overview}
\end{figure}
Our approach, Unsupervised Concept Bottleneck Models (UCBMs), consists of two main steps: (1) learning a concept space through unsupervised concept discovery (\cref{sub:concept_subspace}) and (2) learning an interpretable classifier via supervision on top of that concept space (\cref{sub:interpretable_predictor}).
\Cref{fig:method_overview} provides an overview of \ours and both steps are described in detail below.

It is important to note that \ours does \emph{not} require any human-annotated concepts, nor does it require a predefined set of concepts.
This is in contrast to prior post-hoc methods that required predefined concepts either through the set of human-annotated concepts \citep{yuksekgonul2023posthoc,marcinkevivcs2024beyond} or precomputed text features of a vision-language model \citep{yuksekgonul2023posthoc,oikarinen2023labelfree,marcinkevivcs2024beyond}.
Moreover, the choice of training samples with human-annotated concepts impacts the extracted concepts \citep{ramaswamy2023overlooked} or results in entangled concepts \citep{nicolson2024explaining}.
In contrast, \ours does not assume a priori which concepts the pretrained, black-box model encodes but extracts the ones that most faithfully reconstruct its activations \citep{fel2023craft,fel2023holistic}.

Besides the above, we introduce a novel notion of sparsity for concept-based models in the second step of \ours. Previously, sparsity was applied solely to the weights of the linear model. We found that while this led to sparsity per-class, it did not lead to a sparsity across all classes, \cf, \cref{tab:sparsity}. That is, it does not take the total number of concepts across all classes into account. 
As a remedy, we propose an input-dependent concept selection mechanism that enforces that only a sparse set of concepts influence the classification across all classes.

\paragraph{Notations.}
Let $f:\mathcal{X}\rightarrow\mathbb{R}^p$ be a pretrained, black-box model that maps from an input space $\mathcal{X}\subseteq\mathbb{R}^d$ to an embedding space of a size of $p$. Further, let $\mathbf{X}\in\mathbb{R}^{n\times d}$ be the input data matrix where the $i^{th}$ row is the input $x_i\in\mathcal{X}$ and let $\mathbf{A} = f(\mathbf{X}) \in \mathbb{R}^{n \times p}$ be the activations. Lastly, $\mathcal{Y}$ denotes the binary or categorical class label space.

\subsection{Learning the concept space}\label{sub:concept_subspace}
\paragraph{Unsupervised concept discovery.}
The goal of unsupervised concept discovery is to extract a small set of interpretable concepts $c\in C$.
It is popular in concept-based interpretability to assume a linear relationship between the concepts and activations $\mathbf{A}$ \citep{kim2018interpretability,elhage2022toy}, \ie, $\mathbf{C}\in\mathbb{R}^{p\times k}$, where $k$ is the number of concepts.
As highlighted by \citet{fel2023holistic}, many unsupervised concept discovery methods can be seen as (low-rank) approximation of the activations formulated as an instance of the dictionary learning problem \citep{dumitrescu2018dictionary}: 
\begin{equation}\label{eq:dictionary_learning_problem}
    (\mathbf{U}^*, \mathbf{C}^*) = \underset{{\mathbf{U}, \mathbf{C}}}{\arg \min} ~ ||\mathbf{A} - \mathbf{U} \mathbf{C}^T||_F^2 \qquad ,
\end{equation}
where $\mathbf{U}\in\mathbb{R}^{n\times k}$ is a representation of the activations $\mathbf{A}$ \wrt a new basis (sparse coefficient matrix) spanned by the set of concept activation vectors $\mathbf{C}$ (dictionary matrix), and $|| \cdot ||_F$ denotes the Frobenius norm.
Recent unsupervised concept discoverey methods differ in the constraints they apply on $\mathbf{U},\mathbf{C}$ in \cref{eq:dictionary_learning_problem}:
K-Means ($u_i\in\{e_1,...,e_k\}~\forall i$) \citep{ghorbani2019towards},
PCA ($\mathbf{C}^T\mathbf{C}=\mathbf{I}$) \citep{zhang2021invertible,zou2023transparency},
non-negative matrix factorization ($\mathbf{U}\geq 0,\mathbf{C}\geq 0$) \citep{zhang2021invertible,fel2023craft}, or
sparse autoencoders ($\mathbf{U}=\psi(\mathbf{A}),||\mathbf{U}||_0\leq k$) \citep{makhzani2014k,huben2024sparse}.

We chose non-negative matrix factorization for \ours. Note that our approach will benefit from improvements of unsupervised concept discovery methods such as the recently popular sparse autoencoders.

\subsection{Learning the interpretable classifier}\label{sub:interpretable_predictor}
Previous work showed that sparse linear models are more interpretable than dense linear models \citep{wong2021leveraging}. Sparsity is applied to the weights, resulting in the classification of a particular class being based on only a few features (in our case concepts). 
However, we find that the total number of concepts that are used for the classification across all classes is barely affected by the sparsity.
In fact, we find that most concepts are used in the classification; see \cref{tab:sparsity}.

To also enforce sparsity on the total number of concepts across all classes, we propose a simple input-dependent concept selection mechanism that selectively removes concepts and only retains a small set of concepts.
As a result, classification across all classes will use a substantially fewer number of concepts across all classes. Besides that, the input-dependency of the mechanism also accounts for cases where concepts are not visible in the input image, \eg, due to occlusions.
Below, we first revisit sparsity applied to the weights and then describe our mechanism to achieve sparsity across all classes.

\paragraph{Sparse weights in the linear model.}
We followed previous work and employed sparsity to the weights of a linear model \citep{wong2021leveraging,yuksekgonul2023posthoc,oikarinen2023labelfree}:
\begin{equation}\label{eq:class_level_sparsity}
    \min_{\mathbf{W}, b} \sum_{i=1}^N \mathcal{L}(\mathbf{W}\text{proj}_C f(x_i) + b, y_i) + \lambda_w R_{\alpha}(\mathbf{W}) \qquad ,
\end{equation}
where $\text{proj}_{\mathbf{C}} f(x_i)$ denotes the normalized cosine similarity between activations and concepts,
$\mathbf{W}\in\mathbb{R}^{|\mathcal{Y}|\times k}$ denotes the weights,
$b\in\mathbb{R}^{|\mathcal{Y}|}$ denotes the bias, $y_i\in\mathcal{Y}$ denotes the target class for the $i$th sample for a total of $|\mathcal{Y}|$ classes, 
$\mathcal{L}$ denotes the task-specific loss function,
$\lambda_w$ denotes the regularization strength on the weights $\mathbf{W}$, and
$R_{\alpha}(\mathbf{W}):=(1-\alpha)\frac{1}{2}||\mathbf{W}||_F + \alpha ||\mathbf{W}||_{1,1}$ denotes the elastic net regularization \citep{zou2005regularization}.
Note that $\text{proj}_{\mathbf{C}} f(x_i)$ is frozen.
The sparsity leads to classes relying only on a small set of concepts for their decisions. However, we found that it does not lead to few concepts being used across all classes.

\paragraph{Input-dependent concept selection mechanism.}
To enforce that only a small set of concepts is used across all classes, we propose an input-dependent concept selection mechanism consisting of a gate and sparsity regularization applied to the output of that gate.
Specifically, we define the gate as follows:
\begin{equation}\label{eq:gating}
    \pi(x_i):=\max(0,\text{proj}_{\mathbf{C}} f(x_i)-o) \qquad ,
\end{equation}
where $o\in\mathbb{R}_{+}^{k}$ denotes a trainable offset parameter.
To enforce that only few concepts are used per input $x_i$, we would like to minimize $||\pi(x_i)||_0 ~\forall x_i\in\mathcal{X}$. However, since L0 is non-differentiable, we employ the elastic net regularization on the output of the gate $\pi(\cdot)$.
As a result, our proposed mechanism removes concepts that are unlikely to be present in the input (low normalized cosine similarities) and only retains a small set of concepts per input sample.

\paragraph{Final interpretable classifier.}
Combining \cref{eq:gating} with \cref{eq:class_level_sparsity}, we obtain the final interpretable classifier:
\begin{equation}
    \min_{\mathbf{W}, b} \sum_{i=1}^N \mathcal{L}(\mathbf{W}\pi(x_i) + b, y_i) + \lambda_\pi R_{\alpha}(\pi(x_i)) + \lambda_w R_{\alpha}(\mathbf{W}) \qquad ,
\end{equation}
where $\lambda_\pi$ governs the regularization strength of the sparsity on the number of concepts used in the entire classification decision per input sample.
It is important to observe that the classification decision is still linear \wrt the \emph{active} concepts $\pi(x_i)>0$ for input $x_i$.

\paragraph{Concept dropout.}
Finally, we found that the sparsity on the weights leads the interpretable classifier to over-rely on a single concept.
To reduce over-reliance, we added a dropout layer \citep{srivastava2014dropout} on the output of the gate $\pi(\cdot)$. Note that dropout is applied per concept. Consequently, the interpretable classifier is encouraged to spread its classification across more concepts.
Interestingly, we found that this can even improve downstream performance in our experiments.


\section{Experiments}

We evaluated \ours on diverse image classification datasets and compared it to relevant baselines. We show that \ours achieves better downstream performance to prior works and narrows the gap to their black-box counterparts, while relying on substantially less concepts in its classification. Lastly, we showcase how recent large vision-language models can be leveraged to inform weight editing of the interpretable classifier to fix model errors.

\paragraph{Datasets \& backbone models.}
}.
These datasets cover a diverse set of tasks from standard image classification (ImageNet), fine-grained classification (CUB), to scene recognition (Places-365). The datasets also have very different amounts of training samples (from ca. 5000 to 2~million).

\paragraph{Experimental setup.}
Following \citet{oikarinen2023labelfree}, we set the number of concepts proportional to the number of classes for each task.
Since we have found that the number of concepts substantially influence downstream performance, we used various proportionality factors $\{0.5,1,3,5\}$.
All models were trained on a single NVIDIA RTX 2080 GPU and a full training run takes from few minutes to a maximum of 1-2 days depending on dataset size and number of concepts.
We report top-1 accuracy throughout our experiments.

\paragraph{Implementation details.}
We trained our method with Adam using an initial learning rate of $0.001$ for ImageNet and Places-365, $0.01$ for CUB, and cosine annealing learning rate scheduling for all of them. We used $\lambda_{\pi} = 1e-4$ for CUB and $\lambda_{\pi} = 2e-5$ for ImageNet and Places-365. Further, we penalized the final layer's weights with $\lambda_w = 1e-4$ for ImageNet, $8e-4$ for CUB and $4e-4$ for Places-365. We set $\alpha = 0.99$ for the elastic net regularization and the dropout rate to $0.2$.
The reason for choosing these regularization strengths was that they yielded a good trade-off between downstream performance and sparsity. Our sensitivity analysis in \cref{fig:sensitivity_analysis} provides a comprehensive understanding of the effect of each hyperparameter on the trade-off between downstream performance and sparsity.

\paragraph{Baselines.}
We compared \ours to Post-hoc CBM \citep{yuksekgonul2023posthoc} and Label-free CBM \citep{oikarinen2023labelfree}, as these are the most related to our work. Note that Post-hoc CBM requires annotated concept data to learn the concept space, while Label-free CBM leverage CLIP's text features. Importantly, both approaches require to predefine a concept set a priori.

\paragraph{How sparse are the models' decisions?}\label{par:sparsity}
To understand the sparsity of the models, we computed the mean number of concepts that are used for classification per input sample.
To do this, we computed the mean number of concepts that are retained from the concept selection and also included concepts with a cosine similarity of zero (\ie, $\text{proj}_{\mathbf{C}_j} f(x_i)\approx 0$) as well as ones that are never used in the classification (\ie, null column vectors in the weights of the linear layer).\footnote{We used a small threshold of $1e-5$ to assess whether cosine similarity or the weights are approximately zero, following \citet{oikarinen2023labelfree}.}

\cref{tab:sparsity} shows that the concept selection mechanism leads to substantially less concepts that are used for classification per input sample. For instance on ImageNet, \ours only uses 21 concepts on average (0.7\% of the total number of available concepts). In contrast, Label-free CBM and \ours without concept selection (\& dropout) use on average 4238.0 (93.74\%) or 2999.5 concepts (99.98\%), respectively.
Similar stark differences in sparsity can be observed on CUB and Places-365.
Thus, we posit that this explains the downstream performance advantage of \ours without concept selection \& dropout over \ours (with concept selection) in \cref{tab:downstream_performance}.
To confirm this, we reduced the sparsity by reducing $\lambda_\pi$ as well as the dropout rate. Indeed, we find that the gap closes; see \cref{fig:performance_vs_active_concepts}.

Concept-based models allow us to understand the classification decision for individual input samples. For this we make use of the fact that the decision is linear \wrt to the active concepts ($\pi(x_i)>0$).
Specifically, we computed the contribution of a concept $j$ for an input sample $i$ to output class $k$ as $\mathbf{W}_{j,k}\text{proj}_{\mathbf{C}_j} f(x_i)$, following \citet{oikarinen2023labelfree}. Note that due to the sparsity (\cf, \cref{tab:sparsity}) most contributions will be zero. We show the top-k concepts with the highest absolute contributions to the classification decision of the predicted class.

\cref{fig:explainable_decisions} and \cref{fig:explainable_decisions_other} in \cref{sec:explainable_decisions_other} illustrate which concepts influence the classification the most.
For instance, \cref{subfig:explainable_decision_rabbit} shows that \ours focuses on rabbit concepts such as fur, face, ears, or pawns.
Similarly, \cref{subfig:explainable_decision_goldfinch} highlights that \ours relies on typical concepts of an American goldfinch such as its bright yellow plumage.

\section{Related Works}

\paragraph{Concept-based models.}
The main idea of concept bottleneck models (CBMs) \citep{koh2020concept} is to leverage human-interpretable concepts in their classifications \citep{lampert2009learning,kumar2009attribute}.
Many works highlighted (and partially addressed) the limitations of these types of models \citep{margeloiu2021concept,mahinpei2021promises,havasi2022addressing,marconato2022glancenets,raman2024concept}.
Other works improved the performance-interpretability trade-off \citep{espinosa2022concept,yang2023language} or extended them to image generative models \citep{ismail2023concept} or tabular data \citep{zarlenga2023tabcbm}.
Orthogonal work transformed CLIP \citep{radford2021learning} to a zero-shot, concept-based classifier \citep{menon2023visual}.
Most related to our work are methods that convert a pretrained black-box model into a CBM post-hoc \citep{yuksekgonul2023posthoc,oikarinen2023labelfree,marcinkevivcs2024beyond}. They project the activations of the black-box models' backbone onto a new concept space learned either via supervision or using a vision-language model's text features.
In contrast to prior work, we do not require human-annotated concepts nor a predefined set of concepts.

\paragraph{Concept discovery.}
Early work searched for neuron-aligned concepts \citep{bau2017network,olah2017feature}, while later works, inspired by the superposition hypothesis \citep{elhage2022toy}, went beyond this to (linear) vector \citep{kim2018interpretability,zhou2018interpretable,ghorbani2019towards,zhang2021invertible,zou2023transparency,fel2023craft,huben2024sparse,stein2024towards} or linear subspace \citep{vielhaben2023multidimensional} concept representations.
Early work needed annotated datasets to find concepts that required substantial human effort. Most later works overcame this bottleneck by formulating concept discovery as a dictionary learning problem \citep{fel2023holistic}.
Concurrently, \citet{stein2024towards} compared the representative prowess of discovered concepts of unsupervised concept discovery methods through linear probing.

\paragraph{Model editing.}
The main goal of model editing is to modify a model to remove a bias or rectify model errors.
For instance, it is popular to edit factual knowledge in large language models \citep{zhu2020modifying,meng2022locating}, generative image models \citep{bau2020rewriting,gandikota2023erasing}, or modifying a classifier's prediction rules \citep{santurkar2021editing,oikarinen2023labelfree}.
While previous work relied on, \eg, human intervention or hypernetworks, we leverage recent large vision-language models to inform model editing.


\section{Limitations \& Future Work}

The main limitation of our approach is the need to label the concepts through manual inspection. Thus, we plotted the most activation images for each concept in our figures.
However, this slows down the step of interpretability by a human, as they need to interpret the most activating images first. While we can manually label the concepts, it does not scale to a large amount of concepts.
Promising approaches for automatic labeling could be an adaption of the proposal-ranker framework \citep{zhong2022describing,dunlap2024describing}, multi-modal large vision-language models \citep{achiam2023gpt}, or a combination of the aforementioned.

Another limitation of our approach is that we only extract concepts from the bottleneck layer of the black-box model.
By extracting concepts across the layers of the black-box model, we can effectively leverage a hierarchy of concepts. For instance, an early layer could find concepts for windows, car body, or wheels, while a later layer could encode a car concept \citep{olah2020zoom}. Since such hierarchy is learned and used by black-box models \citep{zeiler2014visualizing}, it is likely that it will also benefit interpretable concept-based models.



\section{Conclusion}

We presented \ours that converts any pretrained black-box model into an interpretable concept-based model without requiring any human-annotated concepts nor a predefined concept set.
We introduced an input-dependent concept selection mechanism that ensures that only a small set of concepts is used per-class as well as across all classes.
We showed that \ours is superior to the baselines, narrows the gap to black-box models, while being substantially more sparse. Finally, we showcased how we can leverage large vision-language models to inform model editing.
