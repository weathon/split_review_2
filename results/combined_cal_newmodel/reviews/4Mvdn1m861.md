## Summary

The paper proposes TOKENCOUNT, a training-free framework for class-agnostic object counting that repurposes SAM's decoder output tokens as a verification signal. It combines probabilistic prompt generation (iterative, probability-guided sampling) with output token-based verification using a TS-SS similarity metric. The method avoids additional models beyond SAM. On FSC-147 it achieves 16.25 MAE (best among SAM-only training-free methods), and on CARPK it achieves 4.68 MAE, outperforming all training-based methods in the comparison.

## Strengths

- **A genuinely underexplored idea: using SAM's output tokens as a verification signal.** The paper identifies that SAM's decoder output tokens jointly encode semantic and positional information, and proposes using this internal representation (rather than image-embedding similarity) as a criterion for counting. This repurposing of tokens SAM already generates during mask prediction is clever and economical. [favorability=12.75]

- **Probabilistic prompt generation is a sensible improvement over grids.** The iterative, probability-guided sampling that suppresses already-verified regions is well-motivated and addresses a real inefficiency in methods that grid the image uniformly or use superpixels. The ablation in Table 4 confirms that this iterative scheme is beneficial. [favorability=12.07]

- **Performance on CARPK is genuinely competitive.** An MAE of 4.68 on CARPK, outperforming all training-based methods in the comparison table, is a concrete result on a real-world benchmark where objects maintain consistent size and viewpoint. [favorability=11.07]

## Weaknesses

### Fatal
None.

### Major

- **Abstract overclaim.** The abstract states: "Experimental results show our method achieves superior accuracy with an MAE of 16.25, outperforming existing training-based and training-free counting methods." This is factually incorrect: TFCAC — a training-free method included in the same comparison table (Table 1) — achieves an MAE of **12.26** on the same benchmark, a 25% relative improvement. The paper itself acknowledges in Section 4.2 that it is "best among training-free SAM only methods," but the abstract makes a broader assertion that would mislead any reader who skims only the abstract. This is not a minor phrasing issue; it is the paper's primary advertised finding. [favorability=-0.18]

- **The core empirical evidence that output tokens are superior to image embeddings is weak.** Table 5 is the only direct comparison under otherwise identical conditions: 16.25 MAE (output token) vs. 16.94 MAE (image embedding) — a ~4% improvement (0.69 MAE). No confidence intervals, standard errors, or statistical tests are reported. The PCA visualization (Figure 5) shows only two qualitative examples. For a paper whose central thesis is that output tokens provide a decisive advantage, this evidence is thin. The paper's own discussion notes that cosine similarity (16.48) is nearly as good as TS-SS (16.25), further undercutting the claimed breakthrough. [favorability=-0.32]

### Minor

- **Computational cost vs. efficiency framing is unsubstantiated.** The best configuration uses a mean of ~1,438 prompts per image (Table 4), each requiring a SAM decoder forward pass. The paper claims "superior computational efficiency compared to state of the art" (line 305) and "more than twice as fast" as TFCAC (line 230), but provides no comparable timing data for any baseline under identical hardware. The stated 1.69s per image is reported without breakdown (encoder vs. decoder passes) and without comparison numbers. Without this, the efficiency claim cannot be evaluated. [favorability=0.11]

- **Key hyperparameters lack sensitivity analysis.** The TS-SS verification threshold of 300 (line 180) is a dataset-specific value for an unbounded metric whose magnitude depends on vector norms and angles, yet no sweep (e.g., 250, 350, 500) is reported. The temperature parameter τ in Equation (1) is referred to indirectly as a "t-scale factor of 0.066" (line 180), but the relationship between τ and this factor is unclear. The NMS IoU threshold is not specified. [favorability=-1.52]

- **The iterative probability update rule is described conceptually but not formalized.** Section 3.1 states that positive regions are "set to 0" and negative regions are "decreased," but the exact update rule (by what factor? using what formula?) is never given. This impacts reproducibility. [favorability=0.68]

### Trivial
None.

## Nice-to-Haves
- A per-category breakdown on FSC-147 would strengthen the claim that output tokens are systematically better than image embeddings.
- A controlled comparison with a uniform grid using the same number of prompts would isolate the contribution of the probabilistic prompt generation strategy.
- The exemplar selection for CARPK (12 random objects from training set) should clarify whether results are averaged over multiple draws or fixed.

## Removed Points
These points are flagged to be removed, treat them with caution:
- **"SAM only vs SAM + α taxonomy inflates contribution"**: This categorization (methods with vs. without additional foundation models) is a standard and reasonable way to organize a comparison table. The paper explicitly acknowledges (Section 4.2) that TFCAC outperforms it. This is a framing preference, not a genuine weakness.
- **"Missing ablation on uniform grid with same prompt count"**: A reasonable suggestion but not a required control; the existing ablation (Table 4) already demonstrates the impact of the iterative scheme.
- **"One-shot results are notably worse"**: The paper frames these as "competitive," which is fair for a training-free method. Not a genuine weakness.
- **"No validation set mentioned"**: The paper explicitly states "Based on validation experiments, we set the token verification threshold to 300" (line 180), indicating a validation split was used. The critic missed this.
- **"No statistical significance reported"**: Soft; most CV papers do not report significance tests. However, the small 4% gap makes this more relevant — folded into the Major weakness about weak evidence.

## Novel Insights
None beyond the paper's own contributions. The reviewers converged on the same core concerns evident from a close reading: the abstract overclaims, the central evidence is thin, and key implementation details and sensitivity analyses are missing.

## Suggestions
1. **Correct the abstract** to reflect the method's actual standing — e.g., "competitive with existing training-free methods and best among SAM-only approaches."
2. **Strengthen Table 5** by reporting confidence intervals, a per-category breakdown, or a statistical significance test (e.g., paired bootstrap) to substantiate the output-token advantage.
3. **Provide comparable runtime** for TFCAC and other baselines under identical hardware, with a breakdown of encoder vs. decoder time per pass.
4. **Add sensitivity analysis** for the TS-SS threshold (sweep over at least 5 values) and explicitly state τ, the NMS IoU threshold, and the probability update factor.
5. **Formalize the probability update rule** as an equation rather than a conceptual description.
6. **Tone down the "efficient" framing** given the ~1,400 decoder passes per image; acknowledge the accuracy-efficiency trade-off more honestly.
