## Summary
The paper proposes a training-free object counting framework that directly repurposes SAM without additional models. It introduces two components: a probabilistic prompt generation stage that iteratively samples prompts from a similarity-based distribution, and an output token-based verification stage that uses SAM’s decoder output tokens with a TS-SS similarity metric to classify positive/negative instances. The method is evaluated on FSC-147 and CARPK, achieving competitive MAEs of 16.25 and 4.68 respectively.

## Strengths
- **Novel use of SAM’s output tokens for counting.** Directly using output tokens as verification criteria avoids the computational cost of similarity operations on image embeddings and requires no auxiliary models.
- **Efficient probabilistic prompt generation.** The adaptive, iterative sampling strategy reduces redundant prompts compared to deterministic grid-based methods, as shown in the ablation study.
- **Comprehensive ablation studies.** The paper isolates the contributions of the verification metric, iterative sampling, and the choice of vector space (output tokens vs. image embeddings), providing insight into each design decision.
- **Strong results on CARPK.** The method outperforms all supervised methods on CARPK (MAE 4.68), demonstrating practical value in a specific real-world scenario.

## Weaknesses
### Fatal
None.

### Major
1. **Overstated claims in the abstract and introduction.** The paper states that the method “outperforms existing training-based and training-free counting methods” with an MAE of 16.25. However, Table 1 shows that TFCAC (training-free, **12.26**), BMNet+ (training-based, **14.62**), SAFECOUNT (**14.32**), and LOCA (**10.79**) all achieve better MAE on FSC-147. This misrepresentation must be corrected; the method is competitive but not universally superior.
2. **Missing statistical reliability.** The probabilistic prompt generation involves multinomial sampling, yet the paper reports only single deterministic numbers without error bars or multiple runs. Given the inherent randomness, results cannot be assessed for stability or significance. Standard practice for such methods is to report mean and standard deviation over several trials.

### Minor
1. **Marginal improvement from the TS-SS metric.** The ablation (Table 3) shows TS-SS achieves MAE 16.25, while cosine similarity achieves 16.48 – a very small gap. The claim that standard metrics are “inadequate” for output tokens is not strongly supported by this evidence.
2. **Unclear derivation of the exemplar output token.** The method relies on an “exemplar output token” (Figure 2) but the paper does not specify how this token is obtained from the exemplar prompt (e.g., whether it is the output token from feeding the exemplar through SAM’s decoder).
3. **Hyperparameter sensitivity not explored.** Key parameters (temperature τ=0.066, verification threshold=300, NMS IoU threshold) are set based on validation but no ablation is provided to show how sensitive performance is to these choices.
4. **Qualitative PCA visualization is limited.** Figure 5 shows only two examples; while suggestive, it lacks quantitative separation metrics. More systematic analysis would strengthen the claim that output tokens provide better separability than image embeddings.

### Trivial
None.

## Nice-to-Haves
- Report results with error bars (e.g., 5 runs with different random seeds) to account for the stochastic prompt sampling.
- Ablate hyperparameter sensitivity (τ, verification threshold, NMS threshold).
- Clearly describe how the exemplar output token is initialized and provide the exact update rule for the probability distribution after each iteration.
- Include a systematic inference-time comparison against other training-free methods beyond a single average processing time.

## Novel Insights
None beyond the paper’s own contributions.

## Suggestions
1. Correct the overclaim in the abstract and introduction to accurately state that the method achieves competitive results, particularly on CARPK, but does not universally outperform all prior methods on FSC-147.
2. Repeat all experiments multiple times (e.g., 5 seeds) and report mean ± std for MAE, RMSE, etc., to demonstrate robustness.
3. Clarify the mechanism for obtaining the exemplar output token and provide the explicit formula for updating the probability distribution (e.g., how values are set to zero for positive regions and decreased for negative regions).
4. Add an ablation study on the verification threshold and temperature τ to show the method’s sensitivity to these hyperparameters.
