## Summary

This paper addresses the training-inference mismatch in tree-based speculative decoding. It contributes two components: (1) **TALF** (Tree-Aware Loss Function), which trains the draft model by aggregating cross-entropy loss over tree nodes generated by the target LLM rather than over a single token sequence, and (2) **SALF** (Stopping at Low Further Gains), an early-stopping criterion for dynamic tree construction during inference that trades off tree quality for drafting overhead. Experiments across 5 benchmarks and 3 model families show that SALF & TALF together achieve 15.6–39.4% speedups over EAGLE-2 and 6.5–24.4% over HASS.

## Strengths

- **Well-motivated and empirically demonstrated problem (Section 3.1, Figure 2).** The paper identifies that prior draft-model training uses sequence-level objectives while inference uses tree structures — a genuine mismatch. Figure 2 provides direct evidence: draft models trained with EAGLE or HASS degrade sharply in accuracy and calibration on lower-ranked tokens, which constitute >10% of actual draft tree nodes. This observation is clean, novel, and clearly motivates TALF.

- **TALF is a simple, principled solution (Algorithm 1, Table 2).** Rather than requiring architectural changes, TALF aggregates cross-entropy loss over tree nodes generated by the target model. Table 2 shows that TALF improves τ over EAGLE-2 and HASS by 7–13% under the same tree construction method, confirming the tree-aware objective is meaningfully different from sequence-level distillation.

- **SALF addresses a real engineering bottleneck (Algorithm 2, Theorem 1, Table 2).** Exhaustive optimal tree search (SpecExec) incurs high drafting overhead, while simple beam search is suboptimal. SALF's early-stopping mechanism halts expansion when aggregate probability gain falls below a threshold. Results are compelling: SALF reduces τ by 2–6% but improves speedup by 14–19% compared to optimal tree search, exactly the expected behavior for an overhead-reduction technique. Theorem 1's monotonicity guarantee provides a clean foundation.

- **Thorough and honest evaluation.** Experiments span 5 benchmarks, 3 model families (Llama-2, Llama-3, DeepSeek-R1), and both greedy and non-greedy sampling. Table 1 shows consistent improvements across all 30 configurations. Table 2 cleanly isolates the separate contributions of TALF and SALF. The top-k sensitivity analysis (Table 3) is informative.

### Fatal

### Minor

- **No variance reporting for main speedup results.** All speedups (Tables 1, 2, 4) are reported as point estimates with no indication of variance, confidence intervals, or number of runs. At temperature=1, speculative decoding involves stochastic sampling, so run-to-run variance exists. While single-run evaluation is common in this subfield, the absence of any variability reporting makes it impossible to assess whether the smaller speedup deltas (e.g., the 6.5–8.1% improvements over HASS on Llama2-7B in Table 1) are statistically reliable. The consistent directional pattern across 30 configurations partially mitigates this concern, but variance reporting would substantially strengthen the evaluation.

- **TALF ablation confounds tree structure with regression-loss removal.** The paper states (line 114) that TALF does not use a regression loss while both baselines do. This means the comparison changes two variables: (a) the loss incorporates tree structure and (b) the regression loss is removed. The top-k ablation in Table 3 partially addresses this (TALF with k=1 ≈ HASS, suggesting regression-loss removal is not the primary driver), but a direct ablation keeping the regression loss (TALF + λ·ℒ_reg) would more cleanly isolate the contribution of tree structure alone.

- **Training protocol asymmetry disadvantages EAGLE-2 in comparisons.** For Llama2-7B and Llama3-8B, EAGLE-2 is evaluated after 10 training epochs, while HASS and TALF receive 3 additional epochs on top of the same base (13 total). The headline improvements over EAGLE-2 (15.6–39.4%) partially reflect unequal training budgets. The HASS comparison (same 13 epochs) is fair and shows consistent gains (6.5–24.4%). The paper is transparent about the protocol but does not acknowledge its impact on the EAGLE-2 comparison.

- **Training tree uses target model distributions, creating its own potential gap.** The training tree is precomputed using the target model (Algorithm 1, line 95), while during inference the draft model constructs the tree based on its own (imperfect) distributions. If the draft model's top-k predictions differ substantially from the target's, the training tree may omit nodes the draft model would actually explore. The paper acknowledges this as a computational necessity (lines 110–111) but does not discuss it as a limitation or potential source of residual training-inference mismatch.

- **Multi-model SALF threshold sensitivity is incomplete.** Table 4 presents the SALF threshold (th) sweep only for DeepSeek-R1, yet the paper claims (lines 264–265) that th=0.6 provides "more consistent performance improvements for the tested target LLMs." This claim about multiple models is unsupported without showing sensitivity data for Llama2-7B and Llama3-8B.
