## Summary

This paper proposes TokenCount, a training-free object counting framework that uses only the Segment Anything Model (SAM) without additional models or fine-tuning. It has two components: (1) a probabilistic prompt generation stage that samples prompts from a multinomial distribution derived from SAM's image embeddings, and (2) an output token-based verification stage that uses SAM's decoder output tokens with a TS-SS similarity metric to distinguish positive from negative instances. On FSC-147, the method achieves an MAE of 16.25, making it the best training-free SAM-only method, and on CARPK it achieves an MAE of 4.68.

## Strengths

- **Novel idea**: Using SAM's decoder output tokens directly as a verification criterion for counting (Section 3.2) is genuinely creative. Prior training-free counting methods rely on cosine similarity in the image embedding space, which is known to be noisy. The paper insightfully identifies that SAM's output tokens encode both semantic and positional information through bidirectional attention, and repurposing these tokens bypasses an unnecessary intermediate similarity step. **[favorability=9.18]**

- **Clean minimalism**: The method uses pure SAM — no DINO, no CLIP, no trainable modules, no architectural modifications. Among training-free counting approaches, this is one of the cleanest and most self-contained setups. **[favorability=7.48]**

## Weaknesses

### Major

- **Abstract overclaims results.** The abstract states the method "achieves superior accuracy with an MAE of 16.25, outperforming existing training-based and training-free counting methods" (line 9). This is contradicted by the paper's own Table 1: training-based methods LOCA (10.79), PseCo (13.05), SAFECOUNT (14.32), and BMNet+ (14.62) all outperform TokenCount's 16.25, and the training-free method TFCAC (12.26) also outperforms it. The body text (Section 4.2) is more measured ("best performance among training-free SAM only methods"), but the abstract and introduction overstate the results. The method is best among training-free SAM-only methods, not across all methods. **[favorability=1.51]**

- **Very high RMSE indicates unreliable performance on difficult cases.** TokenCount's RMSE on FSC-147 is 133.11, which is among the worst in Table 1. Compare: LOCA (56.97, 2.3× better), BMNet+ (91.83), TFCAC (56.33, 2.4× better), and even SAM-alone (137.50). This means the method has very high error variance — it works reasonably on average but fails catastrophically on a substantial number of images. The Discussion acknowledges degradation on dense small instances but does not connect this to the RMSE data or the headline claims. **[favorability=0.77]**

- **Unsubstantiated runtime superiority claim.** Section 4.2 claims TokenCount "features an inference time that is more than twice as fast" as TFCAC, but no runtime data for TFCAC is provided anywhere in the paper. Only TokenCount's own runtime (1.69s/image) is reported. There is no runtime comparison table and no per-method breakdown on the same hardware. This claim should either be substantiated with comparative measurements or removed. **[favorability=-0.11]**

### Minor

- **Marginal improvement from the core technical contribution.** The TS-SS metric improvement over cosine similarity is only 0.23 MAE (16.48 → 16.25, ~1.4% relative) in Table 3. No statistical significance is reported, and with a stochastic sampling procedure this difference could fall within noise. The ablation's own framing that "non-hybrid metrics have reached a performance plateau" undermines the claimed importance of TS-SS. **[favorability=-0.87]**

- **Method underspecification affecting reproducibility.** (1) The exemplar prompt format (point, box, or mask) is never clearly stated in Eq. (1) or Section 3.1, though it feeds into SAM's mask decoder. (2) The probability update rule for negative regions (Section 3.1) is described qualitatively ("the value … is decreased") without specifying the exact mechanism or magnitude. (3) The token verification threshold (300) is stated without sensitivity analysis or explanation of what this value means for the TS-SS product. **[favorability=4.72]**

- **One-shot counting results are weak.** On FSC-147 one-shot (Table 2), TokenCount achieves MAE 18.57. Training-based LOCA achieves 12.53 (48% better), BMNet+ achieves 16.89, and the training-free TFCAC achieves 15.15. The RMSE of 135.86 is tied with the weakest baselines. The paper calls this "competitive performance," but the gap to state-of-the-art is substantial. **[favorability=0.30]**
