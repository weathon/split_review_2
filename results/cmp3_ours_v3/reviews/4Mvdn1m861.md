## Summary

This paper proposes TokenCount, a training-free object counting framework built entirely on SAM, using two components: (1) probabilistic prompt generation that samples point prompts from a similarity-weighted probability distribution, and (2) output token-based verification that uses SAM's decoder output tokens with the TS-SS metric to distinguish positive from negative detections. The method achieves MAE 16.25 on FSC-147 and MAE 4.68 on CARPK without any training or additional models.

## Strengths

- **Novel use of SAM output tokens for verification (Tables 3, 5; Figure 5).** The core idea is well-motivated and supported: output tokens jointly encode semantic and positional information through bidirectional attention with the image embedding, and Table 5 shows the output token space (MAE 16.25) outperforms image embedding space (MAE 16.94) under identical conditions. Figure 5 provides qualitative PCA evidence of better separation. This contrasts with prior SAM-based counting methods (TFOC, C-Anything) that rely on the more ambiguous image-embedding similarity.

- **Clean, genuinely training-free pipeline.** The method requires no fine-tuning, no additional encoders, and no learned modules — only a single SAM model at inference. The reported 1.69s/image runtime on FSC-147 is notable against methods like TFCAC that pay the cost of a second foundation model (DINO).

- **Informative ablation on verification metric (Table 3).** Testing four metrics (dot product, cosine, L2, TS-SS) under identical conditions is the right experiment, and the hierarchy of results provides evidence about the geometry of the output token space.

## Weaknesses

### Fatal
None.

### Major

- **Abstract makes a false headline claim.** The abstract states: "our method achieves superior accuracy with an MAE of 16.25, outperforming existing training-based and training-free counting methods." This is contradicted by the paper's own Table 1: TFCAC (training-free, SAM+DINO) achieves 12.26 MAE on FSC-147, and LOCA (training-based) achieves 10.79. The paper acknowledges TFCAC's superiority in Section 4.2 ("Although our proposed method is inferior in performance to the state-of-the-art TFCAC"), but the abstract's unqualified claim is factually incorrect. Correcting this would fundamentally change the paper's advertised positioning from "superior accuracy" to "competitive accuracy with best efficiency among SAM-only methods."

- **Unexamined catastrophic failure modes suggested by extreme RMSE/MAE ratio.** The RMSE/MAE ratio on FSC-147 is 133.11/16.25 ≈ 8.2×. For context: TFCAC (4.6×), LOCA (5.3×), FamNet (4.5×), C-DETR (7.4×). A ratio this high implies that squared error is ~67× the squared MAE before the square root, indicating large prediction errors on a substantial fraction of images. The paper provides no per-category breakdown, error distribution analysis, or failure-case discussion. The qualitative examples (Figure 4) show only two cherry-picked successes (strawberries at exact count, a parking lot off by 7). Given that FSC-147 has 147 categories, the reader cannot assess whether the method works broadly or catastrophically fails on specific object types. The Discussion (Section 5) mentions "performance degradation in scenarios with dense distributions of very small instances" but provides zero quantitative analysis.

- **TS-SS metric provides only marginal improvement over simpler baselines, contradicting the paper's framing.** Table 3 shows TS-SS (16.25 MAE) vs. cosine similarity (16.48) — a 0.23 MAE improvement (~1.4%) with no statistical significance reported. The paper frames this as "breaking through th[e] barrier" of a "performance plateau" (Section 4.4: "non-hybrid metrics have reached a performance plateau. Breaking through this barrier necessitates a new hybrid metric"). This is disproportionate to the evidence. If the core contribution is the *framework* (probabilistic prompt generation + output token verification) rather than TS-SS specifically, the paper should state this clearly.

### Minor

- **Several implementation details are underspecified.** (a) The verification threshold of 300 is given without stating whether TS-SS > 300 or < 300 indicates a positive match. (b) The iterative algorithm's update rule for decreasing probability values of negative regions is described only as "decreased" with no magnitude specified. (c) The "SAM" baseline (MAE 42.48 in Table 1) is not described — what prompt strategy does it use? (d) For FSC-147, unlike CARPK, the exemplar selection protocol is not described.

- **No variance or statistical significance reported anywhere.** No standard deviations, confidence intervals, or multi-run results are provided for any metric. For an ablation claiming a 0.23 MAE advantage, this is essential to assess whether the difference is meaningful.

- **Probabilistic prompt generation is an incremental contribution with insufficient baselines.** Computing similarity → ReLU → temperature softmax → multinomial sampling is the natural stochastic relaxation of threshold-based selection. The paper does not compare against simpler baselines (e.g., thresholding the similarity map directly, or sampling without iterative updates), making it difficult to assess what the probabilistic framing specifically contributes beyond the deterministic alternatives already in the literature.

- **Only two cherry-picked qualitative examples.** Figure 4 shows only successes; with the extreme RMSE/MAE ratio, representative failure cases would be far more informative.

### Trivial
- The iterative algorithm is described in prose only; a pseudocode box would improve clarity and reproducibility.
