## Summary

This paper introduces CaTS-Bench, a multimodal benchmark for context-aware time series captioning (TSC) built from 11 real-world datasets (20k samples, 570k time steps). It provides numeric series, rich metadata, line-plot images, and validated reference captions — most generated by an oracle LLM pipeline with thorough quality checks, plus 579 human-revisited captions. The benchmark also includes 460 diagnostic Q&A questions across four task types. The paper evaluates leading VLMs in zero-shot and finetuned settings, finding that finetuning improves performance significantly while models struggle with visual grounding, especially in plot matching where most models perform near chance versus near-perfect humans.

## Strengths

1. **Genuinely fills a gap in the TSC benchmark landscape.** Table 1 makes this clear: existing benchmarks (TADACap, TRUCE, TACO) are either small, restricted to one or two modalities, use pattern-oriented/template captions, or lack Q&A tasks. CaTS-Bench is the first to combine numeric series, rich metadata, line-plot images, expressive captions, and diagnostic Q&A at this scale. This is not an incremental advance.

2. **Thorough quality validation of semi-synthetic captions.** The paper goes well beyond typical benchmark validation. The manual check of ~2.9k captions (>98.6% accuracy on statistical claims), the human detectability study (41.1% — near random), and the diversity analyses across multiple embedding models together provide strong evidence that the oracle-generated captions are factual, unbiased, and linguistically diverse. This is the right level of rigor for a benchmark whose references are LLM-generated.

3. **The human-revisited subset is a well-designed complement.** Rather than simply releasing one set of references, the paper provides 579 human-refined captions from 4 domains, sampled from multiple LLM candidates and edited by the authors. This enables evaluation against both a larger semi-synthetic set and a higher-quality gold subset, and the paper reports both, showing consistent rankings (Spearman 0.9266 under paraphrased variants).

4. **The diagnostic Q&A suite is thoughtfully structured.** The four task types (TS matching, caption matching, plot matching, TS comparison) isolate specific reasoning skills rather than collapsing everything into a single generation quality score. The plot matching task, in particular, cleanly tests visual grounding in a way the captioning task cannot.

5. **The plot matching finding — all models near chance while humans are near perfect — is a clean, reproducible demonstration of a genuine VLM limitation** in visual time series reasoning. This is the paper's strongest empirical result.

## Weaknesses

### Major

**1. The captioning-task visual modality finding is confounded by the prompt design.** The evaluation prompt (§3.3) provides the exact numeric values as raw text alongside the line-plot image. When precise numbers are already available textually, it is rational for models to use the more precise modality. The modality ablation (Fig. 4) showing that removing the plot barely changes performance is therefore not strong evidence that models "fail to leverage visual cues" (abstract, conclusion). The plot matching Q&A task provides a clean test of visual reasoning without this confound (models near chance, humans near perfect) and should be the primary evidence for visual deficits. The captioning ablation is still useful as supporting evidence, but the paper's framing oversells its significance. **Why it matters**: The paper's headline empirical claim about visual neglect is weaker than presented, though the plot matching result salvages the core insight.

### Minor

**2. The Q&A test set is filtered adversarially against a single model.** Section 3.4 states that the initial pool of 4k questions per type was filtered "by removing those correctly answered by Qwen 2.5 Omni." This produces a test set whose difficulty is calibrated to one model's particular failure modes rather than representing the natural difficulty distribution. The paper cites Appendix J.2 to argue this produces genuinely harder questions beyond Qwen-specific weaknesses. The methodology is unconventional; a more standard approach would report results on both the unfiltered pool and the filtered set to demonstrate no systematic bias. **Why it matters**: While the appendix likely addresses this concern, the filtering procedure should be better justified in the main text to avoid concerns about benchmark representativeness.

**3. Several domains have very small test sizes.** Table 2 shows Crime (153 test samples), Demography (120), Injury (152), Walmart (109), and Retail (111). The paper correctly macro-averages to mitigate imbalance, but per-domain confidence intervals or variance estimates would help assess whether conclusions hold across all domains or are driven by the larger ones (Health, AQ, COVID). **Why it matters**: Without per-domain breakdowns, it is difficult to know whether findings generalize across all 11 domains.

### Trivial

**4. The "large-scale" framing in the abstract** — "comprising roughly 465k training and 105k test timestamps" — counts individual time points rather than independent samples (20k total). The paper is transparent about this in §3.1, but the abstract and Table 1's "# Timesteps" column present the metric that makes CaTS-Bench appear largest relative to TACO's 2.46b timesteps. The actual sample count is modest relative to typical NLP/vision benchmarks, though appropriate for TSC.

## Nice-to-Haves

- Report confidence intervals or variance estimates for the main 4k-test TSC evaluation (the paper reports low variance for 600-sample repeats but not for the full set).
- Discuss per-domain difficulty variation (which domains are hardest/easiest for models).
- Clarify whether Gemini models' advantage on SS captions partly reflects stylistic alignment with the oracle LLM (Gemini 2.0 Flash). The paraphrasing robustness check addresses evaluation stability but not this potential confound.

## Novel Insights

The reviews surface one genuinely novel observation beyond the paper's own contributions: the captioning task's modality ablation result is fundamentally confounded by providing exact numeric values as text alongside the plot — what appears to be a "visual neglect" finding may partly reflect rational modality selection by models. This reframing actually strengthens the paper's contribution by redirecting attention to the plot matching task, which provides unambiguous evidence of visual reasoning deficits. The broader implication for benchmark design is that multimodal evaluation of time series reasoning must carefully decouple redundant modalities (textual numbers vs. visual plots) to avoid conflating rational modality preference with genuine multimodal integration failure.

## Suggestions

1. **Reframe the visual modality finding** — lead with the plot matching result (models near chance, humans near perfect) as the primary evidence for visual reasoning deficits. Relegate the captioning modality ablation to supporting evidence and explicitly acknowledge the confound that exact numeric values are available in text.
2. **Address the Q&A filtering concern** by either (a) reporting results on both the unfiltered pool and the filtered set to demonstrate no systematic bias, or (b) moving the Appendix J.2 analysis into the main text.
3. **Add per-domain breakdowns or confidence bands** for the main TSC results to address the small-domain variability concern.
