## Summary
Marginal Flow is a density estimation framework that defines the model as a finite average of simple parametric distributions q(x|w_i), where the component parameters w_i = f_θ(z_i) are generated by an unconstrained neural network from base noise and resampled at every training iteration and evaluation. This yields efficient single-step sampling and closed-form density evaluation without bijectivity constraints, while the resampling acts as a regularizer that prevents mode collapse. The paper demonstrates the framework across synthetic datasets, simulation-based inference, Wishart matrix distributions, and image latent space manifold learning.

## Strengths
- **Clear conceptual motivation with controlled ablation (Figure 1):** The paper explicitly contrasts optimizing fixed mixture components (which collapses to a GMM) against resampling them from a learnable distribution (Marginal Flow), using the same nominal number of components (10). Figure 1 shows that resampling prevents collapse and produces a smooth density matching the ground truth — directly validating the core mechanism.
- **Quantitative runtime benchmarks across dimensions (Figure 3):** Wall-clock time for sampling and density evaluation is measured from d=10² to d=10⁵ against NF, FM, and FFF. Marginal Flow operates at ~10⁻³ seconds even at d=10⁵, while NF and FM are 2–3 orders of magnitude slower and eventually run out of memory. This is the strongest quantitative evidence for the efficiency claims.
- **Parametric family flexibility demonstrated at scale (Section 4.3, Figure 9):** By swapping q(x|w) from Gaussian to Wishart, the model handles 100×100 positive-definite matrices (d=5050) — a regime where NF cannot be trained. In the 10×10 setting, test KL for Marginal Flow (~0.0088) is roughly two orders of magnitude lower than NF (~0.82). This cleanly demonstrates that the framework decouples the density estimation mechanism from the choice of parametric family.
- **Training convergence measured in wall-clock time (Figure 7):** Test log-likelihood is plotted against wall-clock runtime across five synthetic datasets. Marginal Flow consistently reaches higher log-likelihood values in substantially less time than NF, FM, and FFF.
- **Multi-modal target recovery from few samples (Figure 5):** Marginal Flow cleanly separates five modes from only 150 training points via log-likelihood training, while FM and NF produce blurred clusters and FFF collapses entirely. This is notable given the mean-seeking forward KL objective.
- **Broad experimental scope:** The paper validates across synthetic densities (forward and reverse KL), SBI, Wishart distributions on positive-definite matrices, and image latent-space manifold learning (MNIST, JAFFE).

## Weaknesses

### Fatal
None.

### Major
- **"Exact density evaluation" framing needs qualification regarding stochasticity (Section 2.1, Table 1):** The model density q_θ(x) is defined as (1/N_c) Σ q(x|w_i) with w_i resampled at each evaluation. For any fixed draw of {w_i}, the density is computed exactly, but the value is stochastic — two evaluations at the same x yield different numbers due to the resampled w_i. This is qualitatively different from the deterministic exact density provided by Normalizing Flows. Table 1 gives both methods the same checkmark under "Efficient exact likelihood" without acknowledging this distinction. The paper should discuss the variance of the density estimate and make clear that the density evaluation, while exact for the sampled draw, is a random variable. This matters particularly for the SBI and scientific applications the paper targets, where reproducible log-likelihood values are important.
- **SBI state-of-the-art claim has zero quantitative support in the main text (Section 4.2):** The paper claims Marginal Flow "achieves state-of-the-art results" on the SBI benchmark as one of four main contribution bullet points, but Section 4.2 consists of a single paragraph referring readers to Appendix Figure 14. No C2ST scores, no baseline comparisons, no tables appear in the main body. This is a significant presentation gap: a claim of this importance cannot be evaluated without numbers in the main text.

### Minor
- **N_c values not stated in the main text for runtime experiments:** Figure 3's runtime comparisons and Figure 7's convergence comparisons are central to the paper's efficiency claims, but the number of sampled components N_c used is not specified in the main text (the reader is directed to Appendix A.3.1). Since N_c directly controls the accuracy–speed trade-off, this should be visible in the main body.
- **Imprecise "not a mixture model" claim (Figure 5 caption):** The caption states "Marginal Flow is not a mixture model" because w_i are resampled. However, the paper itself acknowledges on line 143 that the model "resembles a mixture model with N_c components." At any evaluation point, the model is technically a finite mixture. The true distinction — that components are generated by a neural network and resampled, rather than being fixed parameters — would be better served by precise language like "not a fixed mixture model."
- **Manifold learning precision (Section 2.3, Figure 4):** With Gaussian q(x|w), the model density is strictly positive everywhere in ℝ^d — it does not have support restricted to an m-dimensional manifold. What is learned is a distribution concentrated near a manifold, which is practically useful but not the same as a manifold-supported density. The paper should be explicit about this distinction.

### Trivial
None.
