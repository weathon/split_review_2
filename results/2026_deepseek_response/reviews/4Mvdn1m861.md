## Summary

TOKENCOUNT proposes a training-free object counting framework that repurposes SAM's decoder output tokens for instance verification (using the TS-SS metric) and combines this with a probabilistic prompt generation stage. On FSC-147 it achieves 16.25 MAE (best among SAM-only training-free methods), and on CARPK it achieves 4.68 MAE (outperforming all supervised methods listed in Table 1). The core idea — interpreting SAM's output tokens as combined semantic+positional representations for verification — is genuinely novel for the counting task.

## Strengths

1. **Output token verification outperforms image embedding verification.** Table 5 directly compares the same pipeline using output tokens (16.25 MAE) vs. image embeddings (16.94 MAE) on FSC-147, showing a clear advantage. Figure 5 provides PCA visualizations supporting the claim that output tokens form more separable clusters for positive/negative instances.

2. **On CARPK, surpasses all listed supervised methods.** MAE 4.68 beats SAFECOUNT (5.33), BMNet+ (5.76), and LOCA (9.97) — all of which require category-specific training. This is a strong result for a training-free method.

3. **Among training-free SAM-only methods, achieves best MAE on FSC-147.** Table 1 shows 16.25 vs. TFOC (19.95), C-Anything (27.97), and vanilla SAM (42.48), demonstrating substantial improvement over existing SAM-only counting pipelines.

4. **Probabilistic prompt generation shows consistent improvement.** Table 4 shows a clear monotonic trend: MAE drops from 29.10 (8 iterations, 32 prompts) to 16.25 (16 iterations, 128 prompts), confirming the adaptive sampling effectively distributes prompts.

## Weaknesses

### Fatal
None.

### Major

1. **Abstract overclaims relative to reported data.** The abstract states the method "outperforms existing training-based and training-free counting methods" with MAE 16.25. However, Table 1 shows TFCAC (also training-free, using DINO as an additional encoder) achieves 12.26 MAE — substantially better. The paper's own Section 4.2 correctly qualifies the claim to "best performance among training-free SAM only methods," but the abstract does not. This mismatch is misleading and needs correction.

2. **TS-SS improvement over cosine similarity is marginal (0.23 MAE) with no statistical validation.** Table 3 shows cosine similarity achieves 16.48 MAE vs. TS-SS at 16.25 MAE — a gap of 0.23 MAE. No confidence intervals or standard deviations are reported anywhere in the paper. Given the iterative prompting procedure involves stochastic sampling (multinomial distribution), this difference could easily arise from random variation. The paper's central methodological claim — that output tokens require a hybrid geometric metric like TS-SS — rests on this difference. Without variance estimates, this claim is not empirically supported.

3. **No variance or confidence intervals across any experiment.** All results in all tables (1–5) are point estimates. This is particularly problematic for Tables 3, 4, and 5 where key ablation differences are small (0.23–0.69 MAE). The iterative prompting involves randomness, so variance should be reported.

### Minor

4. **Prompt generation inherits the same cosine-similarity uncertainty the paper criticizes in prior work.** Section 3.1 builds the probability distribution by computing cosine similarity between the exemplar mask embedding and the query image embedding in SAM's image embedding space. The paper criticizes prior work (TFOC) for the "uncertainty of similarity" derived from image embeddings (Section 1). The prompt generation stage itself relies on this same mechanism. An ablation comparing probabilistic prompting against uniform grid prompting at matched prompt counts (with the same verification stage) would disentangle whether gains come from adaptive prompting or the verification mechanism.

5. **Computational cost is high with limited efficiency comparison.** The best setting (16 iterations, 128 prompts) uses an average of 1438 prompts per image on FSC-147. The paper reports its own inference time (1.69 s/image) but does not compare against any baseline's inference time, making the claimed "computational efficiency" difficult to evaluate. TFCAC is described as slower, but no exact comparison is provided.

6. **Prompt generation and verification contributions are conflated in ablation.** Table 4 varies iterations and prompts/iteration together, so it is unclear how much improvement comes from the adaptive prompting strategy vs. the verification mechanism. An ablation comparing probabilistic prompting vs. uniform grid prompting at the same prompt count (with and without output token verification) would cleanly separate the two contributions.

7. **Failure case analysis is not quantified.** Section 5 mentions performance degradation on "dense distributions of very small instances" but does not quantify this — what fraction of images are affected, how much error increases, or any example analysis.

### Trivial
8. Minor: The one-shot setting (Table 2) shows MAE 18.57, which trails TFCAC (15.15) and several training-based methods. The paper appropriately frames this as "competitive," but it further underscores that the core contribution is SAM-only few-shot counting, not a general superiority claim.
