## Summary
This paper reframes DP set union in terms of *missing mass* (ℓ₁ fraction of item occurrences not recovered) rather than cardinality, and proves near-optimal upper bounds for the Weighted Gaussian Mechanism on Zipfian data (Theorem 3.3), matched by a lower bound (Theorem 3.5). A distribution-free ℓ∞ missing mass guarantee (Theorem 3.6) enables extensions to unknown-domain top-k and k-hitting set via a simple two-stage meta-algorithm (WGM for domain discovery + known-domain private algorithm). Experiments on six real-world datasets show WGM-based methods are competitive with or outperform existing baselines.

## Strengths
- **First absolute utility guarantees for DP set union with near-optimality**: Theorem 3.3 provides an upper bound on ℓ₁ missing mass for WGM, and Theorem 3.5 provides a matching lower bound showing the dependence on ε, N, C, and s is essentially tight (both have exponent (s-1)/s on N and ε). Prior work (Desfontaines et al., 2022; Chen et al., 2025) only provided relative guarantees.
- **Clean distribution-free ℓ∞ guarantee (Theorem 3.6)**: Unlike the ℓ₁ bound requiring Zipfian data with s > 1, Theorem 3.6 holds for any dataset and serves as the key enabler for the top-k and k-hitting set results in Section 4.
- **Principled bridging of unknown-domain to known-domain DP**: Algorithm 2 (spending half the privacy budget on WGM, half on a known-domain algorithm) is simple and natural, yielding the first theoretical guarantees for unknown-domain top-k (Theorem 4.3) and k-hitting set (Theorem 4.5). The lower bounds (Corollaries 4.4, 4.6) establish that Ω(k/ε) dependence is unavoidable.
- **Lemma 3.1 connects Zipfian structure to practical bounds**: max_i |W_i| ≤ (CN)^{1/s} provides concrete guidance for setting Δ₀ proportionally to N^{1/s}, and is used throughout the analysis.
- **Empirical validation across diverse datasets and problems**: Experiments on six real-world datasets (Reddit, Amazon Games, Movie Reviews, Steam Games, Amazon Magazine, Amazon Pantry) show WGM-based methods performing competitively across set union, top-k, and k-hitting set.
