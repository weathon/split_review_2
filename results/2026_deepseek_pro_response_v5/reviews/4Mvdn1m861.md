## Summary
TokenCount proposes a training-free object counting framework built on SAM with two components: (1) probabilistic prompt generation that samples point prompts from a similarity-derived probability distribution, and (2) output token-based verification that uses SAM's decoder output tokens with a TS-SS geometric metric to classify prompted regions. Evaluated on FSC-147 (MAE 16.25) and CARPK (MAE 4.68), the method improves over prior SAM-only training-free baselines (TFOC: 19.95, C-Anything: 27.97) and is competitive with some training-based methods on CARPK.

## Strengths
- **Repurposing SAM's output tokens as a verification space is genuinely novel and well-supported.** Table 5 shows output token space yields MAE 16.25 vs. 16.94 in image embedding space, and Figure 5 provides PCA visualizations where output tokens separate positive/negative instances cleanly while image embeddings overlap. The insight that decoder output tokens — which fuse semantic and positional information through bidirectional cross-attention — form a better discrimination space than image embeddings is the paper's strongest contribution.
- **The iterative probabilistic prompting with adaptive distribution updates is well-validated.** Table 4 demonstrates monotonic MAE improvement from 29.10 (8 iter/32 prompts) to 16.25 (16 iter/128 prompts), and the paper transparently reports mean prompt counts per configuration (253 to 1596), enabling accuracy-cost tradeoff decisions.
- **CARPK results are genuinely strong.** MAE 4.68 and RMSE 6.13 beat training-based methods BMNet+ (5.76), SAFECOUNT (5.33), and LOCA (9.97), demonstrating the method's effectiveness when objects have clear boundaries and consistent appearance.

## Weaknesses

### Fatal
None.

### Major
- **The abstract contains overstatements that the results do not support.** The abstract claims the method "achieves superior accuracy with an MAE of 16.25, outperforming existing training-based and training-free counting methods." Table 1 directly contradicts this: TFCAC (12.26), LOCA (10.79), PseCo (13.05), SAFECOUNT (14.32), and BMNet+ (14.62) all outperform 16.25. The claim is only true within the narrow "SAM-only training-free" category. Similarly, "comparable performance to training-free approaches that require additional models" is misleading when TFCAC achieves 12.26 vs. 16.25. These misrepresentations undermine the paper's credibility and must be corrected.
- **No comparison to simpler prompting baselines at matched prompt budgets.** The paper motivates probabilistic prompting by arguing grid and superpixel methods are limited (Section 2.2, Section 3.1), yet never compares against a uniform grid or random sampling baseline. Without this comparison, the value of the probabilistic generation stage — a claimed core contribution — remains unvalidated against the simplest alternative. This is a straightforward ablation.
- **The high RMSE relative to MAE suggests unexamined failure modes.** On FSC-147, the paper achieves MAE 16.25 but RMSE 133.11. By comparison, LOCA (MAE 10.79, RMSE 56.97) and TFCAC (MAE 12.26, RMSE 56.33) have much lower RMSE-to-MAE ratios. This discrepancy — RMSE > 8× MAE for TokenCount vs. ~5× for LOCA — suggests the method produces occasional catastrophic failures that inflate squared error, which the paper never characterizes or discusses quantitatively. Section 5 only mentions "dense distributions of very small instances" as a limitation without analysis.

### Minor
- **The TS-SS metric improvement over cosine similarity is modest and lacks variance.** Table 3 shows TS-SS (MAE 16.25) vs. cosine similarity (16.48), a delta of 0.23 MAE (~1.4%). No standard deviations or confidence intervals are reported, making it impossible to assess statistical significance. The paper presents TS-SS as a core contribution (substantial space in Section 3.2) but the evidence shows marginal gains over standard alternatives.
- **Underspecified implementation details.** The temperature parameter τ in Equation 1 is introduced but never assigned a concrete value. The "token verification threshold to 300" (line 180) is stated without specifying what quantity the threshold is applied to. The number of exemplars used for the main FSC-147 few-shot experiments is not explicitly stated (CARPK gets an explicit "12 objects" but FSC-147 does not).
- **The Discussion section (Section 5) is underdeveloped.** It is a single paragraph that mentions one limitation (dense small instances), pivots to an unsupported "superior computational efficiency" claim, and ends with an ambiguous sentence about scalability.

### Trivial
None.

## Suggestions
- Correct the abstract to accurately reflect the results: the method is best among SAM-only training-free methods, not among all methods. Be precise about which baselines it outperforms and which it does not.
- Add a grid prompting baseline at matched prompt budgets (e.g., uniform grid with the same number of prompts as the probabilistic method) to validate the probabilistic generation stage.
- Report standard deviations or confidence intervals for all metrics, especially for the small deltas in Table 3.
- Add a quantitative failure analysis (e.g., per-image error distribution, examples of worst-case predictions) to explain the high RMSE.
- Specify τ, explain the verification threshold, and state the FSC-147 exemplar count explicitly.
