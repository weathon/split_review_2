## Summary

This paper proposes ASPD, a framework that identifies intrinsically parallelizable segments in LLM responses and decodes them concurrently within a single sequence using branch-invisible attention masks and shared position IDs. The approach combines a non-invasive data pipeline that automatically extracts parallel structure from training data via LLM rewriting/verification, with an internal parallelization module that enables seamless transitions between serial and parallel decoding modes without batching or threading overhead. Experiments on Vicuna-7B and Qwen2.5-7B/32B show 1.3–1.82× speedup on general-domain tasks while maintaining response quality within ~1% of serial fine-tuning, with limited speedups on math reasoning (1.04–1.17×).

## Strengths

1. **Clean, well-motivated architectural design.** The branch-invisible attention mask combined with shared position IDs (Section 3.2, Eq. 1–4) is an elegant solution for within-sequence parallel decoding. It enables concurrent branch generation while preserving causal isolation from each branch's perspective, and avoids the KV-cache discarding (APAR) or pre-allocated ranges (PASTA) problems of prior work.

2. **Practical automated data pipeline.** The four-stage pipeline (parallel rewriting → independence verification → integrity/answer verification → preference-based selection) in Section 3.1 provides a fully automated way to construct training data with explicit parallel structure. This eliminates the need for hand-crafted rules and is reusable by other researchers working on similar approaches.

3. **Credible speed-quality tradeoff on general-domain tasks.** On Vicuna Bench and MT Bench, V-ASPD achieves ~1.82× average speedup while maintaining output quality within ~1% of the serial fine-tuned model (V-Seq). This is a genuinely useful result for latency-critical applications.

4. **Cross-architecture validation.** Results are demonstrated on both Vicuna-1.3-7B and Qwen2.5-7B-Instruct for general tasks, and extended to Qwen2.5-32B-Instruct for math reasoning, showing the method is not tied to a single model family.

## Weaknesses

### Fatal

None.

### Major

1. **Internal contradiction in mask visibility ablation (Section 4.4.2).** The text reads: *"Our empirical evaluation shows that Shared masks consistently outperform Indep masks across both Seq and Max position id configurations."* However, Table 4 shows the opposite: under Seq, Indep scores 7.64 vs Shared 4.64; under Max, Indep scores 6.78 vs Shared 3.70. The paper's own concluding sentence (validating strict branch isolation) is consistent with the table data, confirming this is a one-sentence reversal error. Nevertheless, this is a serious reporting error that reverses the stated empirical conclusion, and it must be corrected before the paper can be cleanly evaluated.

2. **Invariant 44% Proportion of Parallel Data across all four datasets (Figure 1).** The table reports PPD=44% for ShareGPT Vicuna, MRC, RAG, and Math-220K — datasets from fundamentally different domains (general chat, reading comprehension, retrieval-augmented generation, mathematical reasoning) with different response structures generated by different models. While Degree of Parallelism and Average Branch Number vary across datasets, the PPD being exactly 44% for all four is suspicious and unexplained. The authors must clarify whether this is a rounding coincidence, a property of the pipeline acceptance threshold, or a reporting error.

### Minor

3. **Missing parallel decoding baselines on math reasoning (Section 4.3).** The math experiments compare ASPD only against Ori (original model) and Seq (serial fine-tuned). No other parallel decoding methods (APAR, PASTA, Multiverse) are included. While APAR reportedly excluded math tasks, the paper should at minimum discuss why comparisons were infeasible and how ASPD's speedups compare to any available results from concurrent work.

4. **Unspecified LLM driving the data pipeline (Section 3.1).** The pipeline repeatedly refers to "an LLM" for rewriting, independence verification, and integrity verification, but never identifies which model is used. This is essential for reproducibility and for assessing potential circularity — if the pipeline LLM is similar to the trained model, the discovered parallel structures could reflect pipeline biases rather than intrinsic data properties.

5. **No error bars or variance estimates on main results.** The core comparisons (e.g., V-Seq 7.70 vs V-ASPD 7.74 on Vicuna Bench) show very small differences, and without variance estimates the reader cannot assess whether these differences are meaningful or noise. The math experiments report means across 8 seeds for AMC/AIME, but the main general-domain experiments do not.

6. **LLM-as-judge evaluation may be biased by structured output format.** The evaluation uses Qwen3-235B-A22B as judge, but ASPD's output contains special tokens (`<title>`, `<branch>`, `<para>`) that serial outputs lack. The paper does not discuss whether these structural markers could systematically bias the judge's scoring toward or against ASPD outputs.

### Trivial

7. **Minor presentation issues.** The abstract claims "unprecedented performance in both effectiveness and efficiency" — the speedup is real but not unprecedented (SoT achieves higher speedup at lower quality), and quality is essentially tied with serial fine-tuning rather than a leap forward. The discussion contrasting APAR's "predefined rules" with ASPD's automated pipeline could also be sharpened, since ASPD's pipeline also relies on LLM-supplied rules.
