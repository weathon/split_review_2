## Summary
TokenCount is a training-free object counting framework built on SAM that combines (1) probabilistic prompt generation via temperature-scaled softmax over cosine similarity between exemplar and image embeddings, and (2) output token-based verification using SAM's decoder output tokens with the TS-SS similarity metric. Evaluated on FSC-147 and CARPK, it achieves MAE of 16.25 and 4.68 respectively, operating at 1.69s/image using only SAM with no additional models or training.

## Strengths
- **Strong CARPK results**: MAE 4.68 outperforms all supervised methods (LOCA: 9.97, SAFECOUNT: 5.33, BMNet+: 5.76) and all training-free methods except TFCAC (4.39), demonstrating strong generalization to a domain (aerial car counting) quite different from typical counting scenarios (Table 1).
- **Output token verification outperforms image embedding verification**: Ablation in Table 5 shows 16.25 vs. 16.94 MAE (0.69 gap), directly supporting the core thesis that SAM's output tokens carry more discriminative information for counting than image embeddings alone. The PCA visualization (Figure 5) provides qualitative corroboration.
- **Fully training-free with SAM only**: No additional foundation models (DINO, CLIP) or trainable modules required. Reports 1.69s/image on FSC-147, claiming 2× faster than TFCAC which uses an additional DINO encoder.
- **Iterative design validated**: Table 4 shows consistent MAE improvement across prompt budgets (8 iters/32 prompts: 29.10 → 16 iters/128 prompts: 16.25), validating that the iterative expansion mechanism works as intended.
- **Systematic ablation structure**: Tables 3, 4, and 5 each isolate a single design choice (verification metric, iteration/prompt budget, vector space), providing clear evidence for each component's contribution.

## Weaknesses

### Fatal
None.

### Major
- **Misleading presentation of RMSE results**: Table 1 bolds the entire "Ours" row, including RMSE of 133.11, which is the *worst* among meaningful SAM-only baselines (C-Anything: 131.24, TFOC: 132.16; only vanilla SAM at 137.50 is worse). The text in Section 4.2 claims the method "achieved the best performance among training-free SAM only methods" without qualifying this is only true for MAE. A high RMSE relative to MAE indicates occasional catastrophic counting failures that the paper neither acknowledges nor analyzes — no scatter plots, no error distributions, no failure case analysis are provided. This undermines confidence in the method's reliability.

- **Overclaiming in abstract and introduction**: The abstract states the method achieves "superior accuracy...outperforming existing training-based and training-free counting methods" — but LOCA (10.79) and PseCo (13.05) both outperform it on FSC-147 MAE. The claim of "comparable performance to training-free approaches that require additional models" is also strained: TFCAC achieves 12.26 vs. 16.25 on FSC-147, a ~32% relative gap. Only the CARPK results genuinely support the "superior" framing.

### Minor
- **No statistical significance or variance data for small-margin improvements**: The key technical contribution (TS-SS over cosine similarity) yields only 0.23 MAE improvement (Table 3: 16.48 → 16.25). The output token vs. image embedding ablation shows 0.69 MAE (Table 5). Without multiple-run statistics, the reader cannot determine whether these margins are real or noise. The CARPK evaluation also uses randomly selected exemplars (Section 4.1) with no variance reported.

- **No hyperparameter sensitivity analysis**: τ = 0.066 and verification threshold = 300 are set "based on validation experiments" (Section 4.1). For a method whose central claim is being training-free, a simple sweep demonstrating robustness to these choices would substantially strengthen the paper.

- **Discussion section is thin**: A single paragraph that acknowledges "performance degradation in scenarios with dense distributions of very small instances" but provides no experimental analysis of this failure mode. The final sentence ("This limitation affects scalability for real-time applications and large datasets") is vague — it's unclear what limitation is being referenced or how severe the impact is.

### Trivial
None.

## Nice-to-Haves
- A scatter plot of predicted vs. ground truth counts on FSC-147 would illuminate the RMSE-MAE gap and reveal whether errors are concentrated in specific count ranges or categories.
- Inference time comparison with baselines (the paper reports 1.69s/image for TokenCount but no timing for TFCAC or other methods to substantiate the "2× faster" claim).
- Average iteration count and convergence behavior analysis beyond the mean prompt count in Table 4.

## Novel Insights
The paper's genuinely novel contribution is demonstrating that SAM's decoder output tokens — which jointly encode semantic and positional information through bidirectional cross-attention — are a better representation for counting verification than image embeddings alone. The PCA visualization (Figure 5) and the quantitative ablation (Table 5: 16.25 vs. 16.94) provide complementary evidence. The CARPK result (4.68 MAE, beating all supervised methods) is surprisingly strong for a training-free approach and suggests the method has genuine practical value for constrained domains like aerial imagery.

## Suggestions
- Address the RMSE problem directly: provide predicted-vs-ground-truth scatter plots and identify which images/categories produce the largest errors.
- Report variance across multiple runs (especially for ablations) so readers can assess whether the small margins of improvement are statistically meaningful.
- Add a simple sensitivity sweep for the verification threshold (e.g., 200–400) and temperature τ (e.g., 0.03–0.1) to strengthen the robustness claim.
- Correct the bold formatting in Table 1 to only bold metrics where the method is actually best, and qualify the text claims about "best performance" accordingly.
- Expand the Discussion with concrete analysis of failure modes (dense small instances) backed by experimental evidence.
