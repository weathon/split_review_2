## Summary

The paper proposes FormalAlign, a framework for automatically evaluating semantic alignment between natural-language mathematical statements and their Lean 4 formalizations. The method fine-tunes an LLM with a dual loss combining cross-entropy (autoformalization generation) and contrastive learning (representation alignment), producing an alignment score at inference from token log-probability and hidden-state cosine similarity. Evaluated on FormL and MiniF2F test sets with synthetic negative examples, it compares favorably against prompted GPT-4/GPT-3.5 on most datasets and against ablation variants.

## Strengths

- **First automated alignment evaluation framework for autoformalization**: The paper addresses a genuine bottleneck — prior work relied on manual verification or surface metrics (BLEU, compiler validity) that fail to detect semantic misalignment. The running example (Figure 1) where `80 * c = 63` is compiler-valid but semantically wrong concretely motivates the need.

- **Systematic taxonomy of misalignment strategies**: Six distinct misalignment types (constant modification, exponent change, new variable, variable type change, equality flip, random pairing) are clearly defined with Lean 4 code examples (Table 2). This provides a structured evaluation framework beyond existing benchmarks that only contain aligned pairs.

- **Ablation study isolates the contribution of each component**: The ablation in Section 5.2 shows CE-only achieves strong performance on FormL datasets, contrastive-only performs poorly, and the combined loss yields the best across all datasets. This empirically validates that the contrastive loss plays a complementary rather than redundant role.

- **Generalization across multiple base architectures**: The method is tested on Phi2-2.7B, LLaMA2-7B, DeepSeekMath-Base 7B, and Mistral-7B (Section 5.1), showing consistent improvements regardless of base model choice.

## Weaknesses

### Major

- **The headline comparison against GPT-4 conflates fine-tuning with the proposed method's specific contribution**: The paper repeatedly claims "outperforms GPT-4" (Abstract, Introduction, Section 4.3), but this compares a fine-tuned Mistral-7B against a *prompted* GPT-4. A fine-tuned model is expected to outperform a prompted one on the narrow task it was trained on, so this comparison does not isolate the method's novelty. The fair baselines are the paper's own ablations — CE-only (same model, same fine-tuning, without contrastive loss) and the full method. The ablation (Section 5.2) shows the contrastive loss provides *modest* improvements over CE-only, which is a more honest picture of the contribution than the GPT-4 framing implies.

- **The evaluation uses only synthetic negative examples, limiting ecological validity**: All negative examples are generated by 6 hand-designed categorical strategies. A model trained to detect these specific distortion types can achieve high scores without learning general alignment understanding. The near-perfect Alignment-Selection score of 99.21% on FormL-Basic (with 21 distractors per positive) is consistent with the negatives being too easy to distinguish. The paper does not test on naturally-occurring misaligned pairs from real autoformalization systems (e.g., sampling GPT-4 generations and having humans label them), which would be the practically relevant scenario.

- **Human evaluation shows the method is correct only 65% of the time vs. 79.58% for human experts, undercutting claims of "reliable" evaluation**: The paper frames 65.00% as demonstrating "efficient and reliable automated evaluation." Being wrong more than a third of the time means substantial human verification is still required for any high-stakes use. The time savings (2 minutes vs. 3 hours) are a valid practical point, but calling 65% "reliable" for formal mathematical verification oversells the result.

### Minor

- **On MiniF2F-Test (out-of-domain), GPT-4 outperforms FormalAlign (68.31% vs. 64.61%)**, which the paper describes as merely "comparable." The broad claim of "outperforming GPT-4" is contradicted by this result on one of four datasets.

- **The temperature parameter τ in the contrastive loss (Eq. 4) is never given a value**, despite being a key hyperparameter defined in the method's core equation.

- **The threshold θ = 0.7 for alignment detection is stated without sensitivity analysis or justification.** A precision-recall curve over varying θ would strengthen confidence in the threshold choice.

- **The training data size (number of FormL4 + MMA examples) is not stated**, making it hard to assess experimental scale.

### Trivial

- None.

## Nice-to-Haves

- Testing on naturally-occurring misaligned outputs from real autoformalization systems (e.g., GPT-4 generations with human labels) would substantially strengthen practical relevance.
- Analyzing failure cases by misalignment type would reveal systematic blind spots.
- A precision-recall curve for varying θ would help practitioners choose operating points.
