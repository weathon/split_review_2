## Summary
The paper proposes TokenCount, a training-free object counting framework built on SAM. It has two components: (1) probabilistic prompt generation that uses cosine similarity between exemplar and query image embeddings to create a probability map for adaptive point sampling, and (2) output token-based verification that uses SAM's decoder output tokens with the TS-SS geometric similarity metric to distinguish positive from negative instances. The method achieves MAE 16.25 on FSC-147 (best among SAM-only training-free methods) and MAE 4.68 on CARPK (beating most supervised methods).

## Strengths
1. **Output token verification outperforms image-embedding-based verification** — Table 5 directly compares the same pipeline with verification performed in output token space vs. image embedding space. Output tokens achieve MAE 16.25 vs. 16.94 for image embeddings, cleanly isolating the benefit of this core design choice.

2. **Clear ablation hierarchy across four verification metrics** — Table 3 shows a reproducible ranking: dot product (19.58) → cosine similarity (16.48) ≈ L2 distance (16.53) → TS-SS (16.25), supporting the paper's claim that hybrid geometric metrics better suit SAM's dual-natured (semantic + positional) output tokens.

3. **Strong CARPK results from a training-free method** — MAE 4.68 outperforms all listed training-based methods (FamNet 18.19, BMNet+ 5.76, SAFECOUNT 5.33, LOCA 9.97) while requiring no category-specific training data. This is a concretely useful result on a practical benchmark.

4. **Probabilistic prompt generation with adaptive exploration** — The iterative framework with probability updates (setting positive regions to 0, decreasing negative regions) is well-motivated. Table 4 shows monotonic improvement as iterations and prompts-per-iteration increase, confirming the adaptive exploration correctly discovers additional objects.

## Weaknesses

### Fatal
None.

### Major
1. **Abstract makes an unsupported blanket claim** — The abstract states the method achieves "superior accuracy with an MAE of 16.25, outperforming existing training-based and training-free counting methods." Table 1 directly contradicts this: BMNet+ (14.62), SAFECOUNT (14.32), PseCo (13.05), LOCA (10.79), and TFCAC (12.26) all achieve lower (better) MAE on FSC-147. The paper's own Section 4.2 correctly limits the claim to "best performance among training-free SAM only methods," but the abstract is materially false as written.

2. **High RMSE is significant and unaddressed** — The method's RMSE of 133.11 on FSC-147 is barely better than the raw SAM baseline (137.50) and dramatically worse than competing methods (LOCA 56.97, TFCAC 56.33, BMNet+ 91.83, SAFECOUNT 85.54). Since RMSE penalizes large errors quadratically, this implies the method occasionally produces catastrophic counting failures. The paper reports RMSE but never discusses this discrepancy or characterizes the failure cases. This is the most concerning technical issue — it is not a presentation fix but a genuine performance characteristic that readers need to understand.

3. **Ablation does not isolate the benefit of probabilistic prompt generation vs. simpler alternatives** — The paper criticizes grid prompting and superpixel-based prompting, yet Table 4 only varies iteration count and prompts-per-iteration *within* the proposed probabilistic framework. There is no experiment that replaces probabilistic sampling with a uniform grid at comparable prompt density, or with SLIC superpixels. The claimed advantage of probabilistic over deterministic prompt generation is asserted, not demonstrated.

4. **No error bars or variance reporting despite stochastic sampling** — Prompt generation involves sampling from a multinomial distribution, yet all metrics are reported as single-run point estimates. Given the stochasticity, results could vary between runs, and Table 3's TS-SS advantage (0.23 MAE over cosine similarity, a 1.4% relative improvement) may not be statistically significant.

### Minor
1. **FSC-147 split not specified** — The paper does not state whether results are on the val or test split, which is standard practice for this benchmark and affects comparability.

2. **Verification threshold of 300 is undefined** — The implementation details state "we set the token verification threshold to 300" without explaining what this value represents (a distance in embedding space? a TS-SS similarity value?). This is a reproducibility gap.

3. **No runtime comparison against baselines** — The paper reports its own runtime (1.69s/image) and qualitatively claims superior efficiency, but does not report runtimes for competing methods to substantiate this.

4. **TS-SS advantage over cosine similarity is small** — The improvement is 0.23 MAE (16.48 → 16.25), a 1.4% relative gain. Without error bars or multiple trials, it is unclear whether this difference is meaningful or noise. The paper would benefit from significance testing.

5. **Probability update for negative detections is underspecified** — The paper states negative region probability "is decreased" (Section 3.1) but does not specify the factor or magnitude of decrease, affecting reproducibility.

6. **Temperature parameter (τ=0.066) has no sensitivity analysis** — The value is reported without discussion of how it was chosen or how robust results are to its variation.

7. **Tension between criticizing image-embedding similarity and using it for prompt generation** — The paper argues that image-embedding similarity is too ambiguous for verification (motivation against TFOC), yet the prompt generation stage (Eq. 1) uses the same cosine similarity between image embeddings. While the paper distinguishes prompt generation from verification, this tension is never acknowledged or resolved.

## Score and Decision

The paper makes a real contribution: using SAM's output tokens (rather than image embeddings) for verification is a novel and well-motivated idea, and the ablation evidence in Tables 3 and 5 supports this core claim. The CARPK results (MAE 4.68 beating all listed supervised methods) demonstrate practical value.

However, the paper has significant issues that prevent acceptance in its current form: (1) the abstract makes a materially false claim about performance relative to prior work, (2) the high RMSE (133.11, barely better than raw SAM) is a major performance concern that goes essentially undiscussed, (3) a key claimed advantage (probabilistic over deterministic prompt generation) lacks direct evidence, and (4) the lack of variance reporting weakens confidence in the small-but-central TS-SS improvement.

The core technical contribution is solid and worth publishing after revision. However, the gap between what the paper claims and what the evidence supports is too wide for acceptance at a top venue as-is.
