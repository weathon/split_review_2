## Summary
This paper proposes TokenCount, a training-free object counting framework that repurposes SAM via two components: (1) probabilistic prompt generation using cosine similarity-based probability distributions with iterative refinement, and (2) output token-based verification using TS-SS similarity on SAM's decoder output tokens. The method achieves MAE 16.25 on FSC-147 (best among SAM-only training-free methods) and MAE 4.68 on CARPK (surpassing all supervised methods).

## Strengths
- **Novel output token verification with direct empirical support (Section 3.2, Table 5, Figure 5)**: The core idea of using SAM's decoder output tokens rather than image embeddings for verification is genuinely novel and well-motivated. Table 5 directly validates this: output token space achieves MAE 16.25 vs. 16.94 for image embedding space on FSC-147. Figure 5 provides qualitative PCA evidence of better positive/negative separation.
- **Strong CARPK results surpassing all supervised methods (Table 1)**: MAE 4.68 outperforms all training-based methods (LOCA 9.97, SAFECount 5.33, BMNet+ 5.76), demonstrating that foundation model-based training-free methods can exceed trained approaches in constrained domains.
- **Systematic ablation design (Tables 3, 4, 5)**: The paper isolates three orthogonal design choices—verification metric, iteration/prompt hyperparameters, and verification space—with each table controlling a single variable. Table 4's iteration/prompt grid cleanly demonstrates the trade-off between accuracy and computational cost.

## Weaknesses

### Fatal
None.

### Major
- **High RMSE on FSC-147 indicating severe outlier behavior, completely undiscussed**: The method achieves MAE 16.25 but RMSE 133.11 (Table 1). Raw SAM achieves RMSE 137.50, and prior SAM-only method TFOC achieves RMSE 132.16 — meaning the RMSE is *worse* than TFOC while MAE improves from 19.95→16.25. Meanwhile, LOCA achieves RMSE 56.97 and TFCAC 56.33. This pattern (dramatic MAE improvement but stagnant RMSE) indicates catastrophic failures on certain images. The Discussion section (line 305) mentions "dense distributions of very small instances" but never connects this to the RMSE data or quantifies the failure mode. Without per-image error analysis, the paper's accuracy claims are incomplete.
- **Unsubstantiated efficiency claims**: The paper claims "inference time that is more than twice as fast" than TFCAC (line 230) but provides no runtime measurement for TFCAC. The only runtime given is their own 1.69s/image on FSC-147 (line 180). Without comparative measurements, the efficiency trade-off narrative central to positioning against TFCAC is unsupported.
- **Marginal gains from core technical contributions**: TS-SS over cosine similarity is only 0.23 MAE improvement (16.48→16.25, Table 3), and output tokens over image embeddings is only 0.69 MAE (16.94→16.25, Table 5). The "performance plateau" claim (line 275) is based on a 0.05 MAE gap between cosine similarity and L2 distance (16.48 vs 16.53), which may be within noise. The theoretical motivation for TS-SS is extensive but the empirical support is thin.

### Minor
- **SAM variant not specified**: The implementation (line 180) states "We implemented the system using PyTorch and the official SAM" without specifying SAM-B/L/H. Performance and speed differ substantially across variants, making reproduction impossible.
- **Key hyperparameters underspecified**: Temperature τ=0.066 and verification threshold 300 are introduced without justification or sensitivity analysis. These are critical parameters directly affecting performance.
- **No variance reporting**: No standard deviations are reported. For CARPK, exemplars are "randomly selected" (line 174), introducing randomness that is unaccounted for.
- **Misleading abstract claim**: The abstract states "outperforming existing training-based and training-free counting methods" (line 9), but LOCA (10.79), PseCo (13.05), and BMNet+ (14.62) all achieve better MAE on FSC-147.

## Nice-to-Haves

- Sensitivity analysis for the verification threshold and temperature parameter.
- Deeper analysis of when and why output tokens help versus image embeddings (which image types, object densities, etc.).

## Novel Insights
The paper's genuinely novel observation is that SAM's output tokens, which jointly encode semantic and positional information through bidirectional attention in the decoder, provide a better representation for verification than image encoder embeddings. This insight—that the decoder's internal representations are an underexploited resource for downstream tasks—has broader implications for how foundation models can be repurposed. However, the empirical evidence is modest (0.69 MAE improvement), and the high RMSE suggests the benefit may be limited to a subset of images.

## Suggestions
1. **Address the RMSE discrepancy**: Include per-image error distributions, identify which categories/images cause catastrophic failures, and discuss whether this is fundamental to the approach.
2. **Provide comparative runtime measurements**: Measure TFCAC on the same hardware alongside your own 1.69s/image.
3. **Specify the SAM variant**: State whether SAM-B, SAM-L, or SAM-H was used; ideally report all three.
4. **Add sensitivity analysis**: Plot MAE/RMSE as a function of verification threshold and temperature.
5. **Soften abstract claims**: Replace "outperforming existing training-based and training-free counting methods" with precise language about the SAM-only training-free category.
