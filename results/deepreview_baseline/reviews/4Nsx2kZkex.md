## Summary

The paper proposes a framework for safe reinforcement learning in verifiable code synthesis by integrating differentiable approximations of formal verification constraints directly into the policy optimization loop. The key idea is to replace discrete verification oracles with smooth surrogate functions that allow gradient-based updates for both code generation and safety satisfaction. The method is evaluated on benchmark programming tasks, comparing against several baselines and showing improved verification success rates and efficiency.

## Strengths

- The problem of aligning neural code synthesis with formal safety guarantees is important and timely.
- The idea of using differentiable surrogates for verification constraints within RL is novel and could potentially enable more efficient training than post-hoc verification methods.
- The bilevel optimization formulation (inner loop for surrogate alignment, outer loop for policy optimization) is a reasonable conceptual framework for maintaining verification fidelity while allowing gradient flow.

## Weaknesses

### Fatal

1. **Impossible proportions in Figure 2 invalidate experimental results.** Figure 2 reports "Proportion of Generated Code Snippets (%)" that sum to values exceeding 100% (e.g., 191% at epoch 17.5). This is mathematically impossible for a proportion and indicates either a fundamental misunderstanding of the metric, a plotting error, or unreliable data. Since the core experimental evidence relies on these measurements, the validity of the entire evaluation is undermined.

2. **Figure 3 shows negative verification scores, contradicting the method's definition.** Equation 5 defines the verification score as the output of a sigmoid function, which is bounded in [0,1]. Figure 3 plots verification scores as low as -20 and -60, which is inconsistent with the paper's own formulation. This discrepancy raises serious doubt about whether the experiments actually implement the proposed method as described.

### Major

3. **Method description is too high-level for reproducibility and partially unsound.** The differentiable verification surrogates (type safety, memory safety, etc.) are described vaguely—e.g., "sigmoidal relaxations of subtype checking" with an unspecified similarity measure \(S\). The gradient update rule in Equation 7 includes a term \(\lambda \nabla_\theta \tilde{V}(P,\phi)\), but \(\tilde{V}\) is a function of the generated program \(P\), not directly of \(\theta\); the gradient through the stochastic program generation is not properly accounted for. This makes the theoretical formulation questionable.

4. **The experimental comparison is insufficiently controlled.** The best baseline (Syntax-Guided) achieves higher VSR (97.5%) than the proposed method (95.8%), yet the paper claims "superb verification rates." The reported "Verification Efficiency" metric (85 ms) for the proposed method measures run time of the surrogate, while for baselines it includes SMT solving—an unfair comparison since speed is traded for exactness. The paper does not report how often the surrogate is wrong, which is critical for safety guarantees.

### Minor

5. **The hierarchical policy includes a "Low-Level Filter" that is not clearly defined.** The text and figure suggest a filtering step, but the formulation in Equation 10 uses the verification score as a bias in token sampling, not as a filter. The distinction is unclear.

6. **Several sentences are poorly constructed or ambiguous** ("this method introduces modular program synthesis techniques … that decompose verification into composable subproblems, each with a differentiable approximation" — the mechanism is not explained).

## Nice-to-Haves

- Provide a formal guarantee or bound on the approximation error of the differentiable surrogate, and show how it relates to the safety provided at test time.
- Include an analysis of cases where the surrogate disagrees with exact verification, and whether those failures are safe-sided.
- Report confidence intervals or significance tests for all experimental metrics.

## Novel Insights

None beyond the paper's own contributions.

## Suggestions

- Correct the fundamental metric errors: clarify what is being plotted in Figure 2 (proportions cannot exceed 100%) and ensure verification scores in Figure 3 match the sigmoid-defined range.
- Provide a more rigorous derivation of the gradient update, including how \(\nabla_\theta \tilde{V}(P,\phi)\) is computed when \(P\) is generated by \(\pi_\theta\).
- Run the experiments again with corrected measurements and include comparisons of exact verification success (not just surrogate-approximated success) to demonstrate that the differentiable approach does not sacrifice true safety.
- Compare against a baseline that also uses a learned surrogate but with a discrete verification reward, to isolate the benefit of differentiability.

## Score and Decision

Score 3 – reject. The paper addresses an important problem and presents a novel conceptual framework, but the experimental evaluation is fatally flawed (impossible proportions and inconsistent score ranges), and the methodological details are too vague to assess or reproduce. The core claims are not reliably supported.
