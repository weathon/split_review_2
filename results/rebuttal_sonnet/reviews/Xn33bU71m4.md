## Summary

This paper presents a systematic empirical evaluation of nine open-source mid-sized LLMs on two binary reverse engineering tasks—function/variable name recovery and type inference—across four ISA architectures, four compiler optimization levels, and both decompiled and assembly code inputs, using 40,000 unique functions with LoRA fine-tuning.
