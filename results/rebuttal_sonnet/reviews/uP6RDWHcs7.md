## Summary

Marginal Flow defines a density model by marginalizing latent parameters **w** drawn from a learnable distribution $q_\theta(\mathbf{w})$ generated by an unconstrained neural network. The resulting model (Eq. 2) is a finite MC sum requiring only forward passes for both density evaluation and sampling — no Jacobians, ODE solvers, or bijective constraints. The framework is demonstrated on 2D synthetic benchmarks, simulation-based inference, Wishart distributions over positive-definite matrices, and manifold learning in VAE latent spaces.

## Strengths

1. **Efficient runtime** (Figure 3, verified): Marginal Flow is orders of magnitude faster than NF, FM, and FFF for sampling and density evaluation up to $10^5$ dimensions, with OOM errors for NF/FM at high dimensions. This is a concrete, reproducible advantage over a wide dimensional range.

2. **Marginalization prevents GMM collapse** (Figure 1, Section 2.1, verified): The resampling mechanism is clearly motivated and well-illustrated; Figure 1 directly contrasts MF against GMM with the same $N_c$.

3. **Kernel flexibility enables novel settings** (Section 4.3, verified): Swapping to a Wishart kernel handles SPD matrices where NF is computationally infeasible at 100×100 scale — a genuine architectural advantage that no tuning argument can dismiss.

4. **Fast convergence** (Figure 7, verified): On five 2D benchmarks, Marginal Flow reaches higher test log-likelihood faster than all three competitors in wall-clock time.

5. **Manifold learning built in** (Figure 4, verified): Lower-dimensional base distribution naturally learns manifolds, recovering the correct 1D spiral where competitors fail or produce no manifold.

## Weaknesses

### Fatal
None.

### Major

1. **"Exact likelihood" framing in Table 1 and abstract** — The author's defense (the model *is* Eq. 2, Eq. 2 is evaluated exactly) has genuine merit and is better grounded than the original review credited. However, the stochastic nature of the estimate — two calls to $q_\theta(\mathbf{x})$ on the same $\mathbf{x}$ return different values at variance $O(1/N_c)$ — is not surfaced in Table 1. The single checkmark equating MF and NF under "Efficient exact likelihood" remains misleading in the current paper, and the author defers the fix to revision.

2. **No $N_c$ ablation in main text** — The value of $N_c$ used in Figure 3's runtime comparison is deferred to an appendix not available for verification, the cost/accuracy tradeoff is unanalyzed, and the model's central claim cannot be fairly calibrated by a practitioner. All fixes deferred to revision.

3. **Quantitative SBI results buried in appendix** — The "state-of-the-art" claim for SBI (the most concrete performance claim in the paper) is numerically supported only in Appendix Figure 14, which is not in the main text. Fix deferred to revision.

### Minor

1. **Universality claim needs architectural conditions** — The Micchelli citation covers kernel universality; expressivity of $f_\theta$ is separately required but unstated. Fix deferred to revision.

2. **Multi-modal comparison has imperfect controls** — All methods use uniform base (verified), which provides internal consistency, but the structural advantage of a mixture-seeding model over bijection-based models under a uniform base remains uncontrolled.

3. **Wishart NF architecture and training budget not specified in accessible text** — Deferred to Appendix A.4.2. The 100×100 scale architectural argument is convincing; the 10×10 comparison is not self-contained.

4. **MNIST/JAFFE evaluation is entirely qualitative** — No quantitative metrics for disentanglement or interpolation quality. Acknowledged; fix deferred to revision.

## Novel Insights

The method's most genuinely novel observation is that resampling $\mathbf{w}$ from $q_\theta(\mathbf{w})$ at each evaluation — rather than fixing a finite set — prevents collapse to a GMM while enabling exact evaluation of a well-defined finite-sample model. The rebuttal helpfully clarifies that the "exact" qualifier is relative to Eq. 2, not Eq. 1, and that the comparison class is correctly models with no tractable likelihood at all. This clarification is sound and improves the paper's intellectual framing, though it remains unpublished in the current version. The design space question of how variance in Eq. 2 interacts with downstream tasks (posterior inference, log-likelihood ranking) remains an unexplored but potentially high-value thread that would turn the paper's biggest current weakness into a principled contribution.
