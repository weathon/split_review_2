## Summary

This paper proposes TokenCount, a training-free object counting framework that uses SAM without architectural modifications. It introduces two components: (1) probabilistic prompt generation that iteratively samples prompts from a similarity-based probability distribution, and (2) output token-based verification that uses SAM's decoder output tokens with a TS-SS (Triangle Similarity-Sector Similarity) geometric metric. The method achieves MAE 16.25 on FSC-147 and MAE 4.68 on CARPK.

## Strengths

1. **Using SAM's output tokens as the verification representation is a well-motivated and novel design choice.** Prior training-free methods (TFOC, Count-Anything) compute similarity in image-embedding space, which is known to be noisy. Output tokens integrate both prompt-conditioned semantic information and spatial grounding through bidirectional attention. Figures 4–5 and Table 5 provide empirical evidence that output tokens form more separable clusters than image embeddings.

2. **The probabilistic prompt generation with iterative suppression of verified regions is a sensible improvement over uniform grid or superpixel prompting.** Starting from high-similarity regions and adaptively suppressing revisited areas reduces wasted computation on background. Table 4 shows systematic MAE improvement as iteration count and prompts-per-iteration increase, confirming the mechanism works.

3. **The ablation studies are well-targeted.** Table 3 directly tests the central claim about the TS-SS metric against alternatives (dot product, cosine similarity, L2 distance). Table 5 isolates the benefit of output token space vs. image embedding space. These experiments are clean and relevant to the paper's core claims.

## Weaknesses

### Fatal

None.

### Major

1. **The abstract overclaims relative to actual results.** The abstract states the method achieves "superior accuracy with an MAE of 16.25, outperforming existing training-based and training-free counting methods." This is not supported by Table 1: the method is beaten by LOCA (MAE 10.79), PseCo (13.05), BMNet+ (14.62), SAFECOUNT (14.32), and TFCAC (12.26). The paper's own more precise claim in Section 4.2 — "best performance among training-free SAM only methods" — is accurate, but the abstract's broader wording is misleading.

2. **The TS-SS metric provides only a marginal improvement that does not justify its billing as a core contribution.** Table 3 shows TS-SS (16.25 MAE) vs. cosine similarity (16.48) — a 0.23 MAE gap (≈1.4% relative improvement). The paper claims this "necessitates" a new hybrid metric because "non-hybrid metrics have reached a performance plateau," but a 0.23 MAE gap on a dataset with values in the teens does not support this claim, especially without confidence intervals.

3. **No variance or statistical significance is reported.** The method involves stochastic multinomial sampling (Section 3.1), yet every result is a single number. Given the stochastic nature of prompt generation, reporting means and standard deviations over multiple runs is necessary to assess the reliability of the reported improvements, including the 0.23 MAE gap that TS-SS achieves over cosine similarity.

### Minor

4. **The fixed TS-SS verification threshold of 300 is applied uniformly across all images without analysis.** Since TS-SS values incorporate vector magnitudes (Eq. 2–3), which are uncalibrated and likely vary across images and categories, the paper should provide some analysis of the threshold's sensitivity and the range of TS-SS values produced by the model.

5. **One-shot counting performance is noticeably weaker.** The method achieves MAE 18.57 (Table 2), trailing TFCAC (15.15) by 23% and LOCA (12.53) by 48%. Since the one-shot setting is where training-free methods should be most attractive, this weakens the generality claim. The paper's framing of this as "competitive" and "comparable" is generous.

6. **Hyperparameter sensitivity is not reported.** Several hyperparameters are tuned on validation data (temperature τ=0.066, verification threshold=300, iterations=16, prompts/iteration=128, IoU threshold=0.95, patience=5) without any sensitivity analysis. This makes it unclear whether these settings would transfer to new datasets.

7. **No runtime data for competing methods.** The paper claims the method is "more than twice as fast" as TFCAC (line 231) but only reports its own runtime (1.69s/image). A runtime-accuracy Pareto comparison with TFCAC and other methods would substantiate the efficiency claim.

None.

## Nice-to-Haves

- A controlled experiment where the exact same set of prompts is evaluated in both output token space and image embedding space would cleanly isolate the benefit of the verification representation, removing any confounding from different prompt distributions.
- Analysis of output token vector magnitude distributions across positive/negative tokens would help justify why both magnitude and direction are needed in the similarity metric.
- Reporting results with compute budget matched across the prompt generation strategy ablations would strengthen the efficiency claim.
- A sensitivity analysis of the verification threshold (e.g., varying it from 100 to 500) would demonstrate robustness.

## Novel Insights

Beyond the paper's own contributions, the most substantively useful observation from the review is that the claimed core contribution (TS-SS metric) yields only a 1.4% relative improvement over cosine similarity with no variance reporting, which makes it difficult to assess whether the metric choice is meaningful. This is a calibration issue: if the TS-SS improvement is genuine but small, the paper should present it more modestly and support it with significance bounds; if it is not significant, the paper's main technical novelty is weakened.

## Suggestions

1. Revise the abstract to accurately reflect the method's standing: "best among SAM-only training-free methods" rather than "outperforming existing training-based and training-free counting methods."
2. Add variance estimates (standard deviations over at least 3–5 runs) for all main results given the stochastic sampling procedure.
3. Include a sensitivity analysis of the TS-SS threshold and other key hyperparameters (temperature, iterations).
4. Add runtime measurements for competing methods (especially TFCAC) to substantiate the efficiency claim with a clear Pareto comparison.
